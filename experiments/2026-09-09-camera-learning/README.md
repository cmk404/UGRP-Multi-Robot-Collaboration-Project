# 세 기능 적용 결과: 반복은 줄었지만 파지는 실패

요청: 실제 카메라를 유지하면서 행동 기억, 전후 영상 비교, 동작 학습을 모두 적용하고 단점을 확인한다. Issue #30 / PR #24.

## 구현 및 검증 조건

실행 SHA `6d33e089dba10c172edfb5caff6174ff341ed3a0`. 네 조건 모두 seed 11, Gemini 3.8 Flash(응답의 모델명도 확인), 로봇당 30판단/조건당 60호출, 동일한 카메라·화각·640×480 입력·물체·물리·초기 배치. 소스 커밋 후 실행 중 소스를 고정했다. 학습 데이터는 조건마다 초기화했으며 다른 조건 데이터를 미리 제공하지 않았다. 동시에 최대 두 독립 시뮬레이션을 실행했다. 모델 서비스 상태/동시성/실행 순서가 지연에 영향을 줄 수 있어 지연 차이를 기능의 효과로 해석하지 않는다.

- `--mode baseline`: 기존 현재 자기/상단 이미지 두 장만 입력.
- `--mode memory`: 최근 자기 발행 명령 최대 4개 추가. 실제 관절 상태나 실행 성공이 아니다.
- `--mode temporal`: 기억에 직전 자기/상단 이미지 한 쌍 추가. 현재와 과거 모두 원본 JPEG.
- `--mode learned`: 위 기능에 온라인 ridge 영상변화 예측 추가. 2×2 구역별 RGB 평균(두 시점 총 24개)과 자기 명령으로 최대 32개 전이를 학습한다. 실제 시험에서는 로봇당 29개 전이. 동작 종류/서보별 3개 이상 표본과 관측한 명령값 범위 내에서만 예측한다. 이는 작은 상관관계 예측기이며, 파지 시연을 학습한 정책이나 자동 탐색 제어기는 아니다.

고정 설명과 출력 형식은 모드에 맞춰 일관되게 구성했다. 평가 좌표·접촉·관절 상태·동료 명령은 정책이나 학습기에 전달하지 않는다. 실제 요청을 원본 영상 및 이전 자기 명령만으로 재구성해 240건 모두 일치함을 검증했다. 이전 baseline 시험의 60건도 그대로 재현되는 것을 확인했다.

모델 호출 중앙 지연은 기존 7,658ms, 기억 4,912ms, 이전 영상 5,151ms, 학습 4,854ms였다. 실행 wall time은 각각 438.8/332.6/343.2/285.5초. 입력량 증가가 지연 증가로 이어졌다는 결과는 아니다. 추론 중 물리는 정지하므로 실시간 하드웨어 반응 성능도 입증하지 않는다.

## 실제로 확인한 단점

1. **기억이 반복을 줄여도 정확한 제어는 보장하지 않는다.** memory r1은 어깨 1700→1300, 손목 1800→1400 등의 방향 전환을 반복했다. 15번째 부근 자기 영상에서 목표가 사라졌으며, r3는 목표 밖으로 이동했다. 행동 다양성을 파지 능력으로 해석할 수 없다.
2. **과거 영상의 입력 비용이 크다.** memory→temporal에서 입력 토큰이 약 75% 늘었지만 이번 시험에서는 성공으로 이어지지 않았다. 두 영상의 비교만으로 부정확한 동작 방향이나 자기 식별을 해결하지 못했다.
3. **자기 로봇 식별 오류가 남는다.** learned r3의 0기준 round 11 응답은 자신을 아래쪽 로봇이라고 설명했다. 같은 시점의 상단 영상과 출력 전용 평가 위치를 대조하면 r3는 위쪽, r1이 아래쪽이었다. 평가값은 이 사후 검토에만 사용했다.
4. **학습은 시도하지 않은 파지 행동을 만들어 주지 못했다.** 후보는 기본 주행/대기와 최근 실제 명령에서 구성된다. 닫기를 한 번도 선택하지 않아 닫기의 결과를 학습하지 못했다. 모델이 새로운 행동을 스스로 시도해야 한다는 의존성이 남았다.
5. **학습 품질이 로봇마다 달랐다.** 과거 전이만 학습한 모델로 다음 실제 영상변화를 예측하는 사후 검사를 수행했다. 지원 표본이 있는 동일 전이에 대해 r1은 RMSE 0.000769(영상 무변화 예측 0.001299)로 개선됐지만, r3는 0.002062(무변화 0.001590)로 악화됐다. 지원 가능 전이는 각각 15/29, 7/29뿐이다. `check_predictions.py`로 재현한다. 이것은 거친 RGB 특징의 예측 정확도이며 파지 정확도나 명령의 인과 효과가 아니다.

## 코드 검토에서 확인한 구조적 한계

두 로봇이 동시에 움직이므로 상단 변화에 동료의 영향이 섞인다. 학습 경고문은 이를 명시하지만 원인을 분리하지는 못한다. 2×2 색 평균은 작은 집게/물체의 형태와 국소 움직임을 충분히 표현하지 못할 수 있다. 3개 표본과 관측 명령 범위 조건도 충분한 신뢰도를 보장하지 않으며, 여러 명령 항목의 미관측 조합이 범위 안에 들어올 수 있다. 훈련 RMSE는 불확실성이나 성공 확률이 아니다. 또한 학습 모드의 후보 설명 자체가 행동에 영향을 줄 수 있어 학습 수치만의 효과를 분리한 비교는 아니다.

## 판단과 다음 검증

요청한 세 기능은 구현·실행했지만 카메라 기반 파지는 해결하지 못했다. 행동 기억은 이번 시험에서 반복 감소라는 이점이 있었다. 전체 적용을 우월한 기본 정책으로 선언할 근거는 없으므로 CLI 기본값은 baseline으로 보존하고, 전체 적용은 `--mode learned`로 재현한다.

다음 핵심 과제는 실제 카메라를 유지한 채 자기 식별과 동작-영상 관계를 더 정확하게 익히는 것이다. 한 로봇씩 짧게 움직이는 별도 관측 실험으로 동료 영향과 자기 움직임을 분리하고, 새로운 팔 명령을 탐색할 수 있는 정책을 비교하는 것이 후보이다. 아직 이 후속 실험이나 정밀 파지 학습을 완료한 것은 아니다.
