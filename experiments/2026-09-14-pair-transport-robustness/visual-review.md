# 직접 확인한 영상 범위

진단 3개 영상의 시작·중간·끝 9프레임, 최종 6개 영상의 시작·중간·끝 18프레임을
직접 확인했다. 선택 프레임·시간·원본 영상 해시는
[진단 선택 기록](validation/diagnostic-video-review.json),
[최종 선택 기록](validation/final-video-review.json)에 있다.
진단 L자의 내려놓기 종료 프레임은 원래 크기로 추가 확인했다.

좁은 문은 회전해 문을 통과한 뒤 반대편에서 내려놓았고, L자·S자·엇갈린 장애물·우회 분기도
목표 쪽에서 실제 내려놓기 장면을 확인했다. 완전 차단은 파지 후 공동 정지했다.
연속 접촉·높이·경계·목표 충족은 전체 평가 표본과 함께 판정했고 프레임 확인으로 대체하지 않았다.

전달 영상은 실제 MuJoCo `motion.mp4`를 4배속으로 재생하고 제목만 추가했다.
처음의 근접 관찰 카메라에서 넓은 관찰 카메라로 바뀌는 부분은 기존 관찰용 초기화다.
배우의 자기/top 카메라 배치와 FOV는 바뀌지 않았다. 관찰 영상의 phase·높이 자막은 출력
전용이며 배우에게 제공한 원본 RGB에는 없다. 편집 영상은 제어 입력에 사용하지 않았다.
