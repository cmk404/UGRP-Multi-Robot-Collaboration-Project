# 먼 거리 방향 정렬 수정과 전체 E2E 재검증

이전 고정 소스 fd5d68e의 19개 배치 × local/llm 총 38회는 각각 15/19였다.
네 실패 배치 모두 파지 전 영상 정렬에서 중단했다. 기울어진 채 먼 거리를
직진하면서 초기 ±6 cm 이내 좌우 편차가 최대 약 15 cm로 커졌다.
이전 성공/실패 전체 결과는 research-e2e-varied-start-20260916에 보존한다.

이번 변경은 먼 거리 coarse 접근에만 RGB 방향 확인을 추가한다.
공용 TOP의 노란 바퀴 사각형으로 영상 각도를 구한다. 고정 카메라에서
영상 오른쪽을 향하는 기존 작업 배치라는 사전 조건을 사용한다.
±18° 이내 사각형, 바퀴 크기/비율, 네 코너의 픽셀 근거를 검사한다.
영상 각도가 ±1.5° 밖이면 전진하지 않고 회전만 한다. 매 0.2초 새 RGB로
다시 결정한다. 발행 회전 명령을 회전 성공으로 간주하지 않는다.
이 방법은 앞뒤 방향 구분/임의 각도 인식/일반 지형 해결을 보장하지 않는다.
근거리 학습 정렬, 파지, 운반, 평가 기준 및 모델은 그대로 유지한다.

개발 자료: 이전 19개 initial TOP JPEG 38개 로봇 관측에서 모두 검출,
설정 yaw와 방향 반전 영상각 차이 최대 1.341°. 기존 coarse 612개
로봇 관측 모두 형태 검사 통과. 이는 이미 본 자료의 오프라인 진단이다.
정답 setup/evaluation은 이 진단의 평가에만 사용하며 실행 제어에 넣지 않는다.
파일 원본/해시는 tests/fixtures/camera_goal_heading/manifest.json에 있다.

먼저 이전 실패 mixed-far-wide, mixed-near-wide, yaw-opposed10,
mixed-far-mild를 local 진단한다. 각 후보 소스를 실행 전에 커밋하고,
수정이 필요하면 모든 진단 시도와 SHA를 남긴다. 최종 후보는 소스를
동결하고 이전 cases.json 그대로 19개 배치 × local/llm 38회 비교한다.
중간 결과에 따라 코호트를 선별하거나 소스를 수정하지 않는다.
성공 기준: 실제 접근/파지/들기/50±3 cm 운반/내려놓기/해제/안정,
기존 물리 평가 전 항목, 접근 화물 충돌 0, weld 0, 카메라·형상·마찰·질량 불변.
모든 실제 RGB 결정·바퀴 명령·LLM wire를 재생 감사한다.

LLM 역할은 두 로봇의 단계 허가이며 고정 실행 순서와 로컬 제어를 유지한다.
추론 중 SIM 정지 조건도 유지한다. 이번 19개는 이미 본 개발 배치이므로
재검증 결과를 미관측 일반화 또는 반복 확률의 증거로 보고하지 않는다.
시간·명령 수·LLM 호출/토큰을 함께 보고하며 비용은 프록시 미제공 시 미상이다.
각 영상의 균등 표본 프레임과 실패/개선 배치의 실제 입력을 검토한다.
raw는 outputs/에 로컬 보관하고 experiments/에 전체 결과와 해시 및 선택
영상/검토 범위를 기록한다. PR57을 업데이트하되 승인 없이 병합하지 않는다.

## 개발 후보 2: 정지 후 정렬 재획득

후보 2a0f0af의 네 실패 배치 local 진단에서 3/4가 전체 운반 성공했다.
mixed-near-wide는 처음의 학습 범위 이탈을 통과했지만 마지막 lateral에서
정지 전 영상 오차 1.58 mm가 정지 후 2.80 mm로 바뀌었다. 기존 코드는
확인 모드에서 빠져나오지 않아 같은 미정렬 상태로 4회 대기한 뒤 중단했다.

이번 E2E 경로에서만 reacquire_on_settle을 켠다. 정지 확인이 실패하면
해당 프레임에서는 계속 정지하고, 다음 새 RGB부터 보정을 재개한다.
기존 이동 횟수 제한·총 확인 4회·연속 정지 확인 2회·오차 허용 범위는
유지한다. 근거리 실행기 기본 동작은 그대로이며 과거 소스 재생 감사는
기록된 SHA의 접근 루프를 불러와 호환성을 보존한다.
먼저 mixed-near-wide를 다시 진단하고, 통과하면 최종 소스로 같은 38회
코호트를 진행한다. 실패 시 후보와 기록을 남기고 다음 진단을 분리한다.
