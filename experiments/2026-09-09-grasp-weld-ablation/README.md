# 고정 제약 제거 비교: 이전 파지 성공 해석 정정

사용자 질문: 영상의 파지가 부자연스럽다. 물리 엔진 문제인지 확인.

## 결론

동일 코드 SHA `4735bb50d5b5985b51f4ed8e2ef7a84cdad9ef7e`, seed 11, 물체/초기 배치/접촉 판정/서보 동작을 유지하고 weld 활성화만 비교했다. 보조 제약 ON은 두 조건 모두 약 5.3 cm 상승, OFF는 두 조건 모두 상승 실패하고 물체가 바닥에 남았다. OFF 최종 손가락 접촉은 모두 false이고 weld도 모두 false다. 따라서 이전 상승은 마찰 파지 성공 증거가 아니며 고정 제약에 의존했다.

원인 경로: 양쪽 손가락이 물체에 닿음 → 접촉만으로 파지 완료 취급 → gripper와 물체에 weld 활성화 → 물체가 함께 상승. 접촉 두 개가 있다는 사실은 안정적으로 끼워 잡았거나 하중을 지지할 수 있다는 뜻이 아니다. 현 검증은 이 구분을 하지 않았다. 물리 엔진 자체 결함을 입증한 결과가 아니다.
