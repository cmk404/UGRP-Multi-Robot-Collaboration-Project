# 공동 파지 유지 수정: 사전 진단 계획

기준은 PR52 / b1924bb. 기존 94초 실패를 해결하는 작업이며 모든 원본은 outputs/에 로컬 보관한다. main 병합은 별도 승인 후다. 물체/로봇 형상, 질량, 마찰계수, 카메라 위치/FOV, weld OFF를 유지한다.

첫 진단은 stationary 30초 유지와 고정 방출로 한정한다. 기준 NoSlip0, NoSlip1, NoSlip3을 동일한 제어로 비교한다. 초기 파지를 통과하지 못하는 설정은 장시간 시험으로 넘기지 않는다. 필요 시 NoSlip3에서 팔 lift의 기존 명령 보간 중에도 0.1초 RGB 간격 보정을 계속하는 후보를 단독 비교한다. 기존 10.2초 hold, 출발 준비 기준과 물리 성공 기준은 완화하지 않는다. 기존 힘/접촉값을 제어에 넣지 않는다.

출력 전용 진단은 손가락 접촉별 힘/마찰 한계 대비 비율, 접촉 상대 속도, 간격, 물체 및 손가락 높이를 기록한다. 접촉의 존재만으로 성공이라고 하지 않는다. 평가 입력은 actor에 전달하지 않는다. NoSlip은 MuJoCo의 일반 마찰 수치 처리 옵션이며 weld나 부착 제약을 추가하지 않지만, 물리 모델 변경으로 명확히 기록한다. 공식 근거: https://mujoco.readthedocs.io/en/stable/modeling.html#preventing-slip . 물리 설정이 바뀐 성공을 동일 모델의 제어 개선 단독 효과나 실물 검증으로 주장하지 않는다.

성공 후보가 나오면 같은 최종 실행 SHA에서 stationary/shuttle 300초, 180/300초 checkpoint 및 최종 방출을 검증한다. 1cm 높이 감소, 2cm 간격 변화, 10도 기울기, 양쪽 집게 접촉 유지, 지형 충돌 없음 기준을 유지한다. 저장된 실제 RGB로 제어 결정을 재생 감사한다. 그 후 영향받는 여섯 지형을 재검증한다.

미끄러짐 조기 감지는 기존 카메라를 옮기지 않고 물체의 세로 경계 변화가 독립적인 영상 근거가 되는지 먼저 오프라인으로 확인한다. 실제 정답은 학습/평가 표적에만 사용하며 실행 중 감지/회복/단계 전환에 전달하지 않는다. 조기 감지와 회복은 별도 검증하며, 조기 중단을 연속 5분 유지 성공으로 바꾸지 않는다.
