# UGRP — LLM 기반 로봇 협력 이송 연구

각 로봇의 관측과 자연어 통신으로 역할 분담·협력 이송을 검증하는 연구 프로젝트다. 현재 구현은 MasterPi와 MuJoCo 시뮬레이션, 카메라 관측 기반 제어 하네스로 구성된다.

## 현재 검증된 범위

**2026-09-17 목적지·지형 확대 검증: 기본 A만 완주, B 및 장애물 조건은 실패.**
같은 코드·모델로 6개 조건을 각 1회씩 새 LLM 합의부터 실행했다. 기본 A는 다시 완주했지만 B는 빔과 바닥 표시가 영상에서 합쳐져 운반 중 멈췄다.
장애물·협소 통로·요철 4개 환경은 운반 대형 대비 통로 폭 부족으로 실행을 거부했다. 지도에 없는 장애물을 보고 우회를 합의했어도 실제 통과는 못 했다.
[전체 결과·실패 원인·영상 검토·입력 감사](experiments/dispatch-variation-e2e-20260917/README.md). 환경 변화에 대한 안정적인 운반은 아직 미완성이다.

**2026-09-17 공동 출하 E2E: 새 공동 계획부터 빔·상자 운반과 해제까지 완료.**
기존 접근·파지 모델과 상자 운반 스킬을 실제 합의의 담당 로봇·경로·목적지에 연결했다.
세 LLM의 새 합의 후 R1/R3가 빔을 1.702m, R2가 상자를 2.369m 옮겨 같은 출하 구역 A의 각 슬롯에 내려놓았다.
`open / seed11`의 최종 1회에서 물리 성공과 프로토콜 완료를 함께 확인했다. weld OFF, 카메라 배치/FOV 유지.
새 배경의 교사 학습과 집게 접촉 계산 프로필을 적용한 시뮬레이션 결과이며, 좁은 통로·미지 배치·실물 성공은 아직 아니다.
[전체 결과·모델·실패 기록·입력 감사](experiments/dispatch-skill-integration-20260917/README.md) ·
[실행 방법](docs/research_dispatch_arena.md) · [다섯 환경의 실제 장면](experiments/research-dispatch-arena-20260917/index.html).
이전 raw-action D1/D2/D3는 기존 스킬을 연결하지 않아 파지 전에 멈췄으며 [별도 진단 기록](experiments/dispatch-e2e-20260917/README.md)으로 보존한다.

**3대 실행 기본 경로: 목표 합의 → R1/R3 빔 운반 + R2 별도 상자 운반.**
세 독립 LLM이 같은 물체·담당·목적지·완료 조건에 합의한 뒤 두 작업을 함께 실행한다.
자동 선택·먼 구역 지정의 실제 LLM 두 실행과 연결 진단 한 실행 모두 운반·방출·안정을 확인했다.
상자 목적지는 두 구역 중 선택하며, 기술이 지원하는 로봇 조합과 레인은 고정되어 있다.
[구성·실행 방법](docs/three_robot_e2e.md) · [최종 3/3 결과·실패 기록·영상](experiments/three-robot-physical-mission-20260916/README.md).
과거 R2 정지 관찰 구성은 `--inspection-demo`로만 실행하며,
[기존 관찰 구성의 결과](experiments/three-robot-e2e-20260916/README.md)와 구분한다.

**2026-09-16 정렬 수정 후: 출발 배치 19종에서 로컬 19/19·LLM 19/19 성공.**
거리 30–70 cm, 방향 ±10°, 좌우 ±6 cm의 단독·혼합 배치를 같은 고정 소스로 38회 다시 실행했다.
먼 거리에서 영상 방향을 먼저 맞추고, 정지 후 및 마지막 전 축 정렬을 다시 확인하도록 수정했다.
기존 각각 15/19에서 개선됐으며, 접근부터 운반·내려놓기·해제까지 완료했다.
고정 평지·이미 본 배치의 재검증이고, LLM은 로컬 스킬의 실행 허가를 맡는다.
[전체 결과·수정 전후 비교·영상·남은 범위](experiments/research-e2e-heading-fix-20260916/README.md).

**2026-09-16: 두 로봇의 접근부터 목표 구역 운반·내려놓기·해제까지 6/6 완료.**
출발 배치 세 가지에서 로컬 RGB 제어 3/3, 실제 두 LLM의 단계 허가를 연결한 조건 3/3이다.
약 48.2 cm 이동, 목표 오차 1.7–1.8 cm, weld OFF를 확인했다.
고정 평지·고정 역할·시연 팔 동작을 쓰는 조건이며 자율 계획이나 지형 운반 성공을 뜻하지 않는다.
[실행 영상·재현 방법·모든 실패 기록](experiments/research-e2e-local-skills-20260916/README.md)을 참고한다.

**2026-09-09: 표식 없는 작은 상자 단독 운반, 시드42~46에서 5/5 성공.** 현재 RGB/PWM을 사용하는 실제 Gemini 판단으로 접근·집기·우회·운반·방출을 수행했다. 소스 버전, 예산, 결과는 [N7 검증 기준](experiments/2026-09-09-markerless-n7/README.md)에 연결돼 있다.

이 결과는 로봇1대·통신 없음 조건이다. 다중 로봇 협업, 새 시드의 일반 성능, 실물 MasterPi 성공을 뜻하지 않는다. 접근 보정 반복과 불필요한 이동은 아직 개선할 문제다. [진행 이슈](https://github.com/kcm0127-dotcom/ugrp/issues)에서 추적한다.

이후 별도 실행 경로에서 검증한 기능은 다음과 같다. 아래 학생·동기화·지도 주행은 LLM 판단을 사용하지 않으며, 위 Gemini 운반 실행기에 모두 연결된 상태를 뜻하지 않는다.

학생은 자기 RGB·공용 top RGB와 자기 발행 명령을 사용한다. 교사 정답은 학습 데이터 생성에만 허용되며, 실행 중 평가 좌표·접촉·관절 측정으로 행동을 보정하지 않는다. 정적 지도는 승인된 지도 주행 경로의 선택적 입력이다. 실제 카메라 배치/FOV와 weld OFF를 유지한다.

새 팀원은 **[Ubuntu 24.04 시작 안내](docs/ubuntu_quickstart.md)**에서 설치 → 무료 이동·카메라 데모 → 테스트 → PR 순서로 시작한다. 기존 연구 실험은 Mac 로컬 환경에서 검증했다. 예전 클라우드 GPU 실행 환경은 [퇴역 기록](docs/cloud_simulation.md)으로만 남긴다.

## 저장소 운영

변경은 `codex/…` 또는 목적이 드러나는 작업 브랜치에서 수행하고 PR로 검토·자동 테스트 후 `main`에 반영한다. 실험 시작 전에 코드 커밋을 고정하고, 결과를 해당 SHA에 연결한다. 전체 실험 도중 수정한 결과를 하나의 성공률로 합산하지 않는다.

Git에는 코드·설정 예시·회귀 fixture·요약 결과와 일부 실험의 압축 모델·RGB 감사 자료를 저장한다. 각 실험의 manifest와 복원 안내에서 실제 포함 범위를 확인한다. 인증정보·가상환경과 대부분의 raw 영상·대량 로그는 제외한다. 로컬에만 있는 raw 자료를 GitHub 백업으로 표현하지 않는다. UGRP는 Google Drive를 사용하지 않는다.

[초기 연구 브리프](docs/research_brief_20260813.md)는 과거 배경 자료로 보존한다. 위 최신 검증 범위와 구분한다.
