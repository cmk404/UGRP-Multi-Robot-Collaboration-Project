# 카메라 기반 파지 진단 기록 — 2026-09-10

사용자 요청은 카메라만으로 파지가 진행되지 않는 문제 해결이다. 이 기록은 집게의 영상 식별과 국소 접근 제어를 따로 검증한 결과다. **아래 진단의 파지·들기 성공은 확인되지 않았다.** 실제 성공 후보로 채택하거나 두 로봇 협동으로 확대할 근거가 아직 없다.

## 제어 입력과 검증 경계

- 정책 입력은 현재/이전 자기 카메라 RGB, 공용 top RGB, 자기 발행 명령이다. 센서 위치·접촉·관절 측정·평가 결과·다른 로봇 명령을 입력하지 않는다.
- 이번 단계는 결정적인 픽셀 제어 진단이며 모델 호출은 0회다. LLM 협동 결과가 아니다. 앞선 LLM 실험과 baseline은 별도로 보존한다.
- 카메라 위치·시야각·장면·시작 명령·weld OFF를 유지했다. v1–v10은 640×480이며 v11은 같은 소스의 640×480/1280×960 고정 비교다. 시뮬레이터 자세를 복원하거나 물체를 붙이는 제어는 없다.
- 각 실행 전에 코드를 커밋하고 고정 단계 수를 모두 실행했다. RGB 해시와 입력·행동·관측·결정·자기 이력을 평가 파일 없이 정확 재생했다. 모든 결과와 실패를 보존했다.

## 확인한 결함과 변경

1. 집게 개폐로 드러나는 두 움직임 영역을 분리했다. 이것은 움직임 중심·방향이며 정확한 열린 손끝이나 실제 간격이라고 단정하지 않는다.
2. 영상 추적만으로 누적된 이동을 채택하지 않고, 각 동작 뒤 새로운 개폐 관측으로 평가한다. 측정이 실패한 후보는 발행 명령으로 되돌린다.
3. JPEG의 작은 연결부와 주변 픽셀이 집게 방향을 왜곡했다. 여러 대비 임계값의 일치가 있는 측정만 사용한다. 실제 RGB 회귀 fixture와 시각 비교를 보존했다.
4. 원근 때문에 짧아진 own-view 윤곽 및 화면 밖으로 연장된 사각형 끝점을 실제 끝점으로 사용하지 않는다. 관측 가능 항목이 달라지면 같은 오차 항목끼리 비교한다.
5. 반복 개폐만으로 복구되지 않는 시야에서 제한된 look 변경 후 재관측한다. 동일 위치 원시 명령 재생에서 close1500/1000 비교는 둘 다 측정 복구에 실패했다.
6. 단일 동작을 모두 소진한 경우에만 회전→이동→반대 회전 후보를 시험한다. 중간 프레임은 저장하고 마지막 새 측정으로 평가하며, 실패 시 발행 동작의 반대 명령을 역순으로 실행한다. 이는 위치가 정확히 복구된다는 보장이 아니다.
