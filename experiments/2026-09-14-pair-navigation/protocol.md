# 공동 회전·고정 벽 우회 (M2 개발 및 검증)

Issue #39 T4/T5의 작은 시작점이다. 기존 성공한 고정 파지에서 시작하며 두 로봇과
짐의 회전을 영상으로 제어한다. 독립 LLM 협업·실물 성공·미지 장애물 회피가 아니다.

## 고정 조건

- main `1b3b576292e4a3c0b4a66c0af6e56152fc3aed21`의 로봇, 순수 빔, 질량, 마찰, 관절, 카메라/FOV를 유지한다. weld OFF.
- 원래 작업 공간에 지도에 명시한 고정 벽만 추가한다. 기존 물체/지형은 삭제하지 않는다.
- 파지는 검증된 `2026-09-10-rgb-varied-start/models.zip`의 grasp 모델이다.
- 제어 입력은 각자의 own RGB와 공용 top RGB, 자기 발행 명령, 사전 지도 및 고정 카메라 보정이다.
- 현재 위치/회전은 RGB의 바퀴 외관 추적 및 짧은 공동 전진 관측으로 추정한다.
  평가 좌표/관절/접촉/성공 플래그는 실행이 끝난 뒤에만 평가한다.
- 두 독립 로컬 실행기가 동일한 지도·경로 해시를 동의하고 신선한 보고가 있을 때만 GO한다.
- 경로 계획은 두 차체·팔·짐을 포함하는 보수적 사각형과 이동/회전 중의 점유 영역을 검사한다.
- 최종 내려놓기는 기존 시연 재생이며 새로운 RGB 내려놓기 학습으로 주장하지 않는다.

## 순서 및 판정

1. 개발: 빈 공간 좌/우 90도 회전, 영상 추적과 파지 유지 확인.
2. 개발: 고정 벽 한 개를 돌아 반대쪽 목적 구역으로 공동 운반.
3. 최종 소스를 고정하고 좌/우 회전, 벽 우회, 불가능 경로 거부를 재실행한다.
   개발 실패도 전부 결과에 포함하며 개발 결과를 최종 코호트에 섞지 않는다.
4. 추가 비교: 각자 제자리 회전/직선 경로의 기하학적 한계와 최종 경로를 비교한다.
   실제 물리 baseline은 별도 실행한 경우에만 성공률 비교로 제시한다.

이동 중 10 Hz 평가 샘플 **전부** 양쪽 로봇 양손 접촉, lift >= 3 cm, weld OFF를 요구한다.
벽 접촉은 모든 물리 tick에서 검사한다. 목적 위치 오차 <= 8 cm, 방향 오차 <= 10도,
학생 도착 선언, 카메라/물리 불변을 각각 판정한다. 시뮬레이션 시간·행동 수·벽시계 시간과
외부 호출 0회/비용 0달러를 보고한다. 원본 입력을 다시 재생하여 동작과 경로를 독립 감사하고
실제 MP4의 시작·중간·끝 및 실패 구간을 직접 확인한다.

실험 전 실행 소스와 지도 커밋; 코호트 중 소스 고정. 원시 자료는 `outputs/pair-navigation/`
하위 새 디렉터리에 보관하며 위치·전체 해시를 추후 기록한다. 원본은 로컬 보관이며 원격 백업이 아니다.

## 접촉 수치 모델 비교 추가 (개발 실패 후, 비교 실행 전)

`173e930` 좌회전은 로봇만 도착하고 빔은 23.3도에서 떨어졌다. `5f705f1` 정지 유지도
8.9초 뒤 동일하게 실패했다. 손목 +100/-100 pulse 비교는 7.8/8.5초에 실패했다.
초기 법선 접촉력이 손가락마다 약 11.5 N인데 빔이 약 2.55 mm/s로 내려오고 관절은
거의 일정했다. 동작/자세 변경과 분리하여 접촉 연성으로 인한 slip 가설을 비교한다.

[MuJoCo solver 문서](https://mujoco.readthedocs.io/en/latest/modeling.html#solver-settings)의
elliptic 접촉 마찰 임피던스 `impratio`를 1(기존), 10, 100으로 명시적으로 비교한다.
질량·마찰계수·접촉 형상·집게 힘·카메라·weld OFF는 유지한다. `noslip_iterations`는 0이다.
이것은 물리 접촉 수치 모델 변경이며 기존 조건 성공으로 합산하지 않는다. 먼저 장시간
정지 유지와 내려놓기/해제 가능성을 확인한다. CLI 기본값과 기존 실행 경로의 설정은 1이다.
실행마다 실제 컴파일된 옵션을 불변 기록에 보존하고 독립 RGB 실행 및 물리 평가를 반복한다.

첫 60초 유지에서 impratio 10/100은 높이를 유지했으나, 들어 올린 직후 각각 3/1개의
양손 접촉 누락 샘플이 있었다. 판정을 완화하지 않는다. 모든 후속 조건에 동일하게 5초
고정 안정화 시간을 추가하고, 이 구간은 grasp_hold로 보존한다. 새 출발 직전 마지막
2초의 파지 안정성과 출발 후 전 구간의 양손 접촉을 따로 평가한다. 학생은 접촉 판정을
읽지 않는다. 동시에 빔 RGB 방향/중심을 추적하여 차체만 회전하는 경우를 중단한다.

## 최종 코호트 사전 고정

벽 조건에서 출발 전 접촉 누락이 더 늦게 나타났다. 별도 정지 진단에서 21.1, 21.2,
21.5 SIM초(파지 종료 후 4.5, 4.6, 4.9초) 이후 32.5초까지 추가 누락이 없었다.
최종 조건 모두에 8초의 고정 안정화를 사용하고 마지막 2초 안정성 판정을 유지한다.
이 대기는 접촉/정답을 읽고 연장하는 동작이 아니다.

- 동일 최종 SHA: left90 / right90 / wall-detour / blocked-passage, impratio=10.
- 동일 최종 SHA·동일 8초 대기: 기존 impratio=1 left90 실패 및 RGB 분리 감지 확인.
- 추가 진단: impratio=10 60초 유지 후 공중에서 집게 열기; 자유 낙하로 부착 제약 부재 확인.
- 기본 수치 모델은 1을 보존하며 성공 예시는 명시적인 `--impratio 10` 조건이다.
- 엄격한 판정에 출발 직전 2초 파지 안정, 이동 샘플 연속성, 수평, 전체 형상 지도 경계,
  모든 물리 tick의 벽/다른 물체 충돌, 마지막 내려놓기 후 접촉 해제를 추가한다.
- 이 코호트는 고정 파지·고정 지도별 1회 검증이다. seed 일반화나 실물의 수치 보정은 입증하지 않는다.
