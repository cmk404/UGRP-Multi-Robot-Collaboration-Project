# ACT 운반·방출 연결 및 기준선 재검증

2026-09-22 사용자 요청으로, 교사 성공과 ACT 전체 실패 사이의 실행 차이를 고친다. 실행 소스 b21b9c20에서 4회 재검증을 완료했다.

- ACT가 raw TOP RGB를 읽을 때 빔 추적 상태도 갱신해 기존 내려놓기 경로로 전달한다. 모델 입력은 기존 raw 영상·정적 작업·자기 명령 이력이고, 추적 좌표를 ACT 입력이나 조향 보정에 전달하지 않는다. 영상에서 추적을 잃으면 기존 RGB 추적기가 오류를 반환하며 정답으로 보정하지 않는다.
- 첫 30회 계획의 최대 wall 한도 900초를 새 검증에서 원래 2400초로 복원한다. `--carry-max-steps`를 지정하면 RGB/ACT에 같은 900회 판단 예산을 적용한다. 기존 옵션을 사용하지 않는 실행의 기본 예산은 보존한다. 시간 초과와 판단 예산 소진은 별도 원인이다.
- 기존 900초 실행은 소스 88e5b2f의 별도 진단으로 보존한다. 완료 12회 이후 잘못된 설정의 추가 실행을 중지했다. 진행 중 중단·미실행은 모델 실패로 더하지 않는다. `superseded-first-wave.json`에 당시 결과를 남겼다.
- 원 성공 ACT seed18 체크포인트와 당시 접근/파지 보정 11개 JSON 해시를 검증한다. open-minus에서 RGB 교사와 원 ACT가 먼저 재현되어야 교차로 교사와 기존 RELEASE 실패 사례를 추가 실행한다. 실패 시 원인을 재진단하며 잘못된 기준선으로 대규모 비교를 시작하지 않는다.
- 옛 보정과 새 native 보정을 섞어 모델 순위를 계산하지 않는다. 이번 재검증은 4회이며 반복 실패율·맵 다양화 재학습 결과가 아니다.

## 검증

회귀검사는 raw 영상·모델 창·실행 명령 이력이 유지되는지와 내려놓기 때 RGB 추적이 이어지는지를 확인한다. 실패 원본 RGB와 순서대로 추적한 직전 상태를 fixture로 보존한다. 전체 회귀와 실제 실행 결과를 아래처럼 구분한다.

실행 전 전체 회귀: **1276 passed, 3 skipped, 191 subtests passed**, 96.77초. 원 ACT/교사의 원래 출발 조건이 이전 프로토콜과 일치함을 확인했다. 이 결과는 물리 성공을 뜻하지 않는다.
