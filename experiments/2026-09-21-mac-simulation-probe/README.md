# Mac 네이티브 시뮬레이션 선택 진단

사용자가 이 Mac 실행을 제안한 뒤, 기존 환경에서 모델을 호출하지 않는 규칙 시행 하나를 유한하게 실행했다. M3·16GB, 실제 OpenGL vendor Apple / renderer Apple M3, CGL이다. 다른 앱·기존 Kaggle 평가를 중단하지 않았다.

소스 `049091653fa4b93e16690af2f96eac68f3a9fdfd`. 앞선 Colab 소스 `8baa01f` 이후 차이는 CPU 진단 기록과 CI 테스트 등록뿐이며 actor·물리·인식·영상 코드는 같다. `dev_open`, full, paused, 제어 목표 4 SIM초, 벽시계 150초, 자식 180초 한도로 동일하게 구성했다. 각 실행 SHA/원본/파일 해시는 verification.json에 남긴다.

| 실행 환경 | actor 시간 | 종료 이유 | 최종 SIM 시각 | 명령 수 |
|---|---:|---|---:|---:|
| Mac CGL / Apple M3 | 7.4039초 | sim_budget: 지정 제어 구간 완료 | 7.80초 | 23 |
| Colab OSMesa / llvmpipe | 165.8930초 | wall_budget: 지정 제어 구간 미완료 | 5.55초 | 14 |

SIM 시각은 초기화·탐색·정리까지 포함한다. 두 실행의 완료 구간 길이와 렌더러가 다르므로 정밀한 배수 성능 비교를 주장하지 않는다. Mac의 전체 자식 프로세스 시간은 8.94초다. 현재 구성에서는 Mac이 CPU Colab보다 훨씬 실용적이라는 근거이며 T4 GPU와의 비교가 아니다.

Mac RGB 입력·해시·명령·카메라 불변·weld OFF·영상 저장 검사를 통과했다. 원본 102개 파일 해시를 재검증했고 영상은 별도 확인한다. 제한 시간 내 과제 성공률 실험이 아니며 원본 success=false를 유지한다. 실제 모델 호출은 0회다. 종료 후 소유 프로세스 그룹이 stopped임을 확인했다.

권장 배치: Mac에서 시뮬레이션 및 외부 Jev/Gemini API 평가를 우선 한 개씩 수행하고, 큰 ACT 학습은 Kaggle GPU에 둔다. 현재 열려 있는 앱과 메모리 사용을 감안해 곧바로 여러 병렬 worker를 시작하지 않는다. 기존 Kaggle 108회 평가는 유지하며 기존 GPU 실패율 코호트에 Mac 결과를 섞지 않는다. 이 진단만으로 전체 학습/평가의 영구 기본 설정을 변경하지 않았다.

TensorBoard `0921-Mac진단`에 같은 진단의 CPU 기준선(기존 0921-CPU진단 스냅샷)과 함께 볼 수 있도록 신규 Mac 결과만 추가한다. 화면/영상 검증은 원본 폴더의 tensorboard.json에 저장한다. 사용한 실행 소스 0490916의 CI 6종은 앞선 작업에서 통과했으며 이번에는 실행 코드 수정이 없다.
