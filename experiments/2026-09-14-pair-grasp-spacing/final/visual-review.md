# 시각 검토 범위

`observer-review-selection.json`에 기록한 6개 원시 관찰 영상의 4프레임씩, 총 24프레임을 직접 확인했다. 각 영상의 대기 종료, 운반 중간 두 시점, 종료를 선택했다. 전후 비교 영상의 52·72·90번째 프레임 쌍도 직접 확인했다. 전체 원시 영상을 사람이 프레임마다 검토했다는 의미는 아니다.

- 좁은 문: 넓은 간격으로 파지 대기를 유지하고, 물체를 회전해 문을 통과한 뒤 반대편에서 내려놓은 상태를 확인했다.
- L자: 모서리 주변 회전과 수평 방향 운반, 목적 위치의 내려놓기 상태를 확인했다.
- S자: 서로 다른 통로 구간에서 하중을 든 모습을 확인했고 마지막에는 바닥에 내려놓았다.
- 교차 장애물: 장애물 사이에서 기울어진 진행 방향으로 움직이는 장면과 목적지의 내려놓기를 확인했다.
- 막힌 분기: 긴 벽 끝을 돌아 반대편으로 이동한 뒤 내려놓은 상태를 확인했다.
- 완전 차단: 초기 방향 확인 구간 뒤 막힌 벽으로 진입하지 않고 짐을 든 채 공동 정지했다.
- 같은 관찰 카메라 영역을 확대한 전후 비교에서, 기존 대기의 후반에는 두 베이스가 안쪽으로 가까워졌지만 1600 PWM 후보는 대기 종료까지 원래 간격을 유지했다. 영상 레이블은 종료 시점의 출력 전용 거리이며, 실시간 제어 정보가 아니다.

선택 프레임에서 눈에 띄는 벽 관통이나 하중 낙하는 보이지 않았다. 전 운반 구간의 접촉·lift·간격·충돌 여부는 별도의 0.1초 간격 평가와 접촉 이벤트 검사로 확인했다. 원본 선택, 평가 지표, RGB 입력 감사는 서로 다른 검토 범위다.
