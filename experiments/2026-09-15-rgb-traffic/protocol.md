# RGB 기반 두 로봇 통로 예약 — 사전 프로토콜

기반 main `1b3b576292e4a3c0b4a66c0af6e56152fc3aed21`. #49의 첫 단계이며 PR44–53의 미병합 파지 코드를 요구하지 않는다. 실행 소스와 이 프로토콜을 먼저 커밋한 뒤 파일럿을 수행하고 실패도 보존한다. 최종 후보가 정해지면 별도 SHA로 아래 전체 조건을 다시 고정 실행한다.

## 1차 구현 범위

짐 없는 r1/r3의 서로 다른 목표. 원래 카메라/FOV/로봇 몸체·외관과 weld OFF 유지. 지도에 선언된 서로 분리된 시작 구역에서 RGB 외형을 연결하며 실제 시작 좌표나 방향을 actor에 전달하지 않는다. 방향은 원래 주행기의 RGB 동작 보정으로 얻는다. 자기 RGB를 저장·디코딩하지만 현재 위치·주행은 공용 top RGB로 판단한다. LLM 호출 0회.

중앙 coordinator가 원형 차체의 전체 경로 swept capsule을 보수적으로 독점 예약한다. 공간 구간 사이 교차·정면 엇갈림·추종도 검사한다. 예상 시간에 따라 경로 일부를 비우는 최적화는 없다. FIFO와 ID 동률 순서를 사용하고, 기다리는/완료된 로봇의 현재 footprint도 장애물로 유지한다. 순환 다중 자원 획득을 피하기 위해 전체 경로를 원자적으로 예약한다. 막힌 출구는 임의 후진하지 않고 상위 재계획이 필요함을 남긴다.

반경 .18m, RGB 불확실성 .035m, 정지·지연 여유 .08m는 파일럿 가정이다. 실제 최대 RGB 오차와 정지 이후 변위를 평가 출력에서 측정한 후 본실험 전에 유지/수정 여부를 고정한다. GO는 최대 .6초, 포트 watchdog은 각 명령 만료에 정지한다. 관측 간격은 발행한 명령 중 최대 .6초. 보고가 빠지면 양쪽 HOLD이며 최신 공통 라운드 보고로만 재개한다. coordinator 재시작은 저장된 예약을 보존하고 epoch를 바꾼다.

TTL·예상 도착·새 plan version은 점유를 해제하지 않는다. 기존 주행기의 영상 도착 확인 이후, 두 새 프레임에서 정지·다른 요청 경로 밖에 있는지 확인해야 CLEAR/RELEASE한다. 늦은 로봇의 경로를 다른 로봇에게 넘기지 않는다. 변경된 점유 중 계획은 자동 실행하지 않고 재계획 필요 상태로 보존한다. 이는 완전한 임의 계획 복구나 분산 협상이 아니다.

파일럿 `57b6027`의 head_on은 첫 경로에서 8.2cm 떨어진 영상 추정 지점에서 예약 범위 이탈로 정지했다. 주행기의 정상적인 A* 경로 갱신이 예약에 연결되지 않은 원인이었다. 후속 후보에서는 기존 경로와 4cm 넘게 달라지면 같은 작업 계획의 route version을 증가시켜 제안하고, 다른 예약/현재 로봇과 겹치지 않을 때만 기존 점유를 유지하면서 예약 경로를 확장한다. 허가 세대 토큰은 바뀌며 기존 경로는 도착 시 RGB CLEAR 전까지 보존한다. 서로 다른 task/plan 변경은 여전히 자동 처리하지 않는다.

## 검증 조건

파일럿 교차로의 표본 대응 최대 위치 오차는 2.84cm로 초기 .035m 가정 안이었다. 최종 후보에서는 RGB와 같은 시각의 truth를 평가 전용 파일에 표본 번호와 함께 기록해 정렬 오차를 제거한다. 이는 actor로 반환되지 않는다. 두 번째 head_on 파일럿은 207라운드/78.96 SIM초에 양쪽 도착, 접촉 0, 최소 표본 원형 여유 21.19cm였다. 이 결과를 바탕으로 반경/오차/정지 여유/GO 한계를 그대로 고정하고 최종 8조건을 실행한다. 최종 평가가 오차 가정을 넘으면 그 한계와 실패를 그대로 기록하고 필요 시 새 후보를 별도 검증한다.

1. crossing: 직교 교차. 같은 설정에서 독립 주행 대조와 예약 조건.
2. head_on: .76m 폭의 좁은 구간을 반대 방향으로 통과, 양끝 분리된 대기/목표 공간.
3. following: 같은 방향 앞뒤 출발. 앞 로봇 목표는 뒤 로봇 경로 밖.
4. delayed_owner: crossing과 동일, 24–35라운드 r1 구동만 보류. 관측이나 완료 보고는 조작하지 않는다.
5. report_gap: 24–28라운드 r1 보고 누락, 최신 두 보고 뒤 재개.
6. restart: 24라운드 예약 상태를 저장·복원하고 epoch 변경.
7. blocked_exit: r3가 r1 출구에 주차. 71라운드 후 안전 거부로 별도 집계. 도착 성공으로 세지 않는다.

각 조건은 파일럿 이후 최종 1회이며 일반 성공률이나 통계 우위를 주장하지 않는다. 무충돌 양쪽 도착, 대기 후 재개, 보존 제약을 함께 판단한다. actor의 영상 도착과 별도 truth 목표 거리(.10m 이내)는 각각 평가한다. 접촉·weld는 모든 물리 step, 자세·경계·최소 간격·경로는 .1초 표본으로 측정한다. 실패/timeout도 결과에 포함한다. 기본 최대 300판단 라운드.

저장 RGB·지도·보고·실제 발행 명령만 재생한 감사가 동일 결정을 내야 한다. 동기화 단위 테스트에는 누락/중복/역순, 만료/이전 GO, 계획 변경, 점유 중 재시작, 경로 구간 중간 충돌, 대기 출구 교착을 포함한다. 실제 영상 대표 프레임을 검토한다. 모델 호출·비용, SIM/실제 시간과 행동/대기 수를 기록한다.

장시간 파지 PR53의 결과는 이전에 검증된 별도 범위다. 이번 실행은 무부하 2대이며 공동 하중+다른 로봇, 두 운반 팀, LLM 계획·재계획(#50), 고수준 통신 비교(#51), 실물은 다음 단계다. 기록은 로컬과 Git, raw RGB/원본 영상은 로컬 보관이며 해시만으로 원격 백업을 주장하지 않는다. main 병합은 별도 명시 승인 대상이다.
