# RGB approach and grasp from varied start poses

요청: 시작 위치가 고정되지 않아도 접근하고 물체를 함께 들어 올릴 수 있도록 검증한다.

각 로봇의 시작 거리를 15–40 cm, 좌우 위치를 ±6 cm, 방향을 ±10° 안에서 독립적으로 바꿨다. 고정된 장면·물체·카메라·로봇별 측면 배정 안에서의 시작 변동을 다룬다. 지도 전체의 임의 위치, 장애물 회피, 다른 물체·조명, 실물 로봇은 검증 범위가 아니다.

## 최종 결과

| 조건 | 전체 집기 성공 | 접근 SIM 시간 중앙값 | 로봇별 접근 판단 수 중앙값 |
|---|---:|---:|---:|
| 새로운 시작 30개 / 최종 모델 | 29/30 | 33.95 s | 324 |
| 같은 시작 30개 / 이전 직선 전용 모델 | 0/30 | 0.25 s | 2 |
| 기존 직선 시작 20개 / 최종 모델 | 20/20 | 16.75 s | 152 |

전체 집기 성공은 물체가 3 cm 이상 들리고, 두 로봇의 양쪽 집게 접촉이 있으며, 보조 weld가 꺼진 상태가 연속 2초 이상 유지된 경우다. 접근만 성공한 경우는 전체 성공으로 세지 않았다. 로봇별 판단 수에는 영 명령과 정지 확인도 포함되며, 두 로봇은 같은 물리 시간에 움직인다. 모든 실행의 접근 중 물체 접촉은 0회다.

사전 통과 기준은 새 시작 ≥27/30, 기존 시작 ≥19/20, 접근 중 물체 접촉 0회이며 최종 판정은 **PASS**이다. 30개 새 조건은 학습이나 튜닝에 사용하지 않았고, 최종 코호트를 확인한 뒤 모델을 변경하지 않았다.

이전 직선 전용 모델의 실패는 새로운 영상이 학습 범위를 벗어난다고 판단한 조기 정지다. 대부분 행동을 시도하지 않은 조건이므로, 0.25초 종료 시간을 성공한 접근의 속도와 비교하면 안 된다.

### 실패와 제한

- `heldout-19`: stationary RGB confirmation budget exhausted.

`heldout-19`는 마지막 좌우 정렬 뒤 정지 확인 4회에서 r3가 허용 범위에 들어오지 못했다. 마지막 RGB 추정 오차는 2.773 mm, 정지 허용치는 2.5 mm였다. 집기를 시작하기 전에 멈췄고 물체는 바닥에 남았다. 이는 영상 판정의 실패 기록이며 실제 위치 오차와 같은 값이라고 해석하지 않는다. 실패를 제외하거나 재시도 성공으로 바꾸지 않았다.

## 구현과 입력 경계

접근은 고정 상부 카메라의 로봇별 영상 영역에서 위치와 방향 오차를 추정한다. 좌우·전후 오차는 학습한 영상 특징 회귀, 방향은 영상 정합과 학습한 보정으로 추정한다. 각 로봇이 회전 → 좌우 → 회전 → 전진 → 회전 → 좌우 → 전진 단계를 거치고, 각 단계에서 새 정지 영상 두 장으로 준비 상태를 확인한다. 마지막에는 모든 축을 다시 검사한 뒤 기존 RGB 집기 모델을 실행한다.

움직일 때는 정지 허용 오차의 75%를 목표로 한다. 정지 허용치는 방향 0.006 rad, 좌우 2.5 mm, 전후 4 mm다. 바퀴의 측정된 마찰 때문에 움직임 명령에는 0.01의 최소 크기를 적용한다. 거친 방향 추정은 접근에만 쓸 수 있고 최종 집기 허가에는 정밀 방향 추정이 필요하다.

오프라인 교사는 시뮬레이터의 실제 상태를 사용해 라벨과 시범을 만들 수 있다. 학생의 실행 입력에는 카메라 RGB, 저장된 모델, 자기 명령 이력과 단계 정보만 들어간다. 시작 위치는 초기 장면 설정에만 쓰고, 실행 중 실제 좌표·속도·접촉·평가 로그는 학생에게 전달하지 않는다. 카메라 위치를 옮기거나 실행 중 로봇/물체 위치를 직접 변경하지 않는다. 현재 결과는 학습한 로컬 시각 제어의 성능이며 LLM 협업 성능을 측정한 것이 아니다.
