# 파지 후 로봇 간격 축소 수정

현재 6개 지형의 동일한 시작 조건에서 통과 가능한 5개 경로의 운반·내려놓기와 완전 차단 지형의 공동 정지를 모두 확인했다. 실행 SHA `f8deb28f5f321893cb11a3ab17ee5b6623dcac79`. 결과 저장 커밋은 실행 이후 문서·검증 증거만 추가한다.

파지 닫힘 직후 간격은 약 65.06 cm다. 기존 실행은 출발 전에 54.23 cm로 줄었지만 최종 후보는 64.93 cm를 유지했다. 전체 들어올리기·대기 구간 최대 간격 변화는 0.614 cm, 운반 중 최대는 0.172 cm다. 들어올리기·대기·운반 중 접촉 상실과 전체 실행의 벽·기타 충돌, weld 사용은 모두 0이다.

## 원인과 수정

기존 1500 PWM의 강한 닫힘과 하중이 걸린 대기에서 로봇 베이스가 안쪽으로 미끄러졌다. 이 현상은 첫 주행 명령 전에 발생했고, 기존 평가가 마지막 2초의 안정성만 검사해 놓쳤다. 이전 출력 전용 진단에서 팔의 안쪽 도달 길이는 약 17.1–17.3 cm로 유지됐으므로 팔을 5 cm씩 접은 동작은 아니었다.

- 고정 닫힘 명령을 1500 → 1600 PWM으로 완화했다. 첫 hold 표본의 손가락 접촉력은 출력 전용 비교에서 약 11.55 → 7.92 N이었다. 이 힘을 제어에 입력하지 않는다.
- 닫힘 직후 RGB로 로봇 위치와 간격을 기억하고, 기존 대기 시간을 0.1초 간격 영상 감시·보정으로 수행한다. 기준 위치를 현재 미끄러진 위치로 재설정하지 않는다. 영상 손실이나 복구 범위 초과 시 함께 정지한다.
- 전체 들어올리기·대기 및 운반에 간격 변화 2 cm 이하 기준을 추가했다. 기존 접촉·lift·수평·충돌·도착·내려놓기 기준도 유지한다.

카메라 배치/FOV, 형상/외관, 지도, 물리/마찰/접촉 설정(`impratio=10`), grasp 모델 파일, 초기화·RGB 팔 보정·들어올리기 명령은 기존 코호트와 동일하다. 실제 닫힘 명령의 차이는 의도적으로 기록한다. 확인 결과는 [불변 조건 검사](final/invariants-audit.json)에 있다.

## 실패와 진단도 보존

총 18회 물리 실행: 짧은 파지 진단 5회, 좁은 문 운반 진단 1회, 1700 PWM 전체 코호트 6회, 최종 1600 PWM 전체 코호트 6회.

- 최초 1500 PWM + 영상 보정 후보는 포트 명령 한도 초과로 중단했다. 한도 수정 뒤에도 간격 복구 범위를 초과했다.
- 1700 PWM은 영상 보정 ON/OFF 모두 짧은 파지에서 최대 간격 변화 0.569 cm와 접촉 상실 0을 보였다. 따라서 초기 개선의 주된 변경은 닫힘 완화이며, 이 비교는 영상 PD 보정이 필수라는 증거가 아니다. 최종 1600 PWM의 수동 대기 대조군은 별도로 실행하지 않았다.
- 1700 PWM 전체 운반은 3/5였다. 좁은 문과 교차 장애물에서 긴 운반 중 물체가 점차 내려가 grip_stop에 도달했다. [전체 실패 코호트](failed-1700-cohort/results.json)와 영상·입력 감사·원본 해시를 보존했다.
- 1600 PWM의 짧은 파지와 좁은 문 운반 진단을 통과한 뒤, 최종 설정의 전체 코호트를 다시 실행했다. [모든 진단](diagnostics/summary.json)에 실행 SHA와 실제 결과가 있다.

## 범위와 재현

동일한 시작 자세·물체·카메라에서 지형당 1회인 시뮬레이션 비교다. 다양한 시작 자세, 다른 하중/마찰, 실물 로봇이나 무제한 장시간 유지의 성공을 입증하지 않는다. 영상 위치 추정과 사전 지도 기반 A*·결정론적 제어이며, LLM 적응 협업 결과로 부르지 않는다. 내려놓기는 기존 고정 시연을 재생한다. 최장 운반 90.7 SIM초까지 검증했다.

실행 소스는 사전 커밋 후 코호트 동안 고정했다. `run_cohort.py`의 기본값은 robust + visual spacing + 1600 PWM이며, 다른 PWM은 명시적 진단 옵션이다. 명령과 모델 파일 해시는 [cohort.json](final/cohort.json), 환경은 [environment.json](final/environment.json)에 있다. 현재 로컬 모델 경로는 `/Users/changmin/projects/ugrp-worktrees/pair-loaded-navigation/outputs/pair-navigation/runtime/models/grasp`다. 모델/raw 자료가 Git만으로 내려오는 것으로 표현하지 않는다.

원본 RGB·영상·전체 로그는 `/Users/changmin/projects/ugrp-worktrees/pair-grasp-spacing/outputs/pair-spacing-final1600-2026-09-14`에 로컬 보관한다. [해시 목록](final/raw-hashes.jsonl.gz)과 [실제 저장 범위](final/raw-manifest.json)를 함께 기록한다. 선택 영상·요약·검증 결과는 Git에 보존하며 raw의 원격 백업을 뜻하지 않는다. UGRP 프로젝트 예외에 따라 Drive는 사용하지 않는다.
