# 3대 최소 연결 검증 사전 계획

목적: 현재 검증된 R1/R3 운반에 세 로봇의 버전 합의와 R2 영상 관찰을 연결한다.
자유로운 역할 분담·통신 효과 비교 실험으로 해석하지 않는다.

1. 오프라인: 다른 계획 ACK, 이전 요청/버전, 세 번째 응답 누락, 계획 철회,
   지원하지 않는 운반 조합, 보고 단절·이전 영상 재사용을 거부하는지 검사한다.
2. 연결 진단: `team-planner=fixture`, `planner=local`, 정상 60/60cm 시작 조건 한 번.
   R2 관찰은 UNCERTAIN fixture다. 실제 운반 물리와 스레드·기록 연결만 평가한다.
3. 최종 소스 고정 후 실제 모델 3조건을 각각 한 번 실행한다.
   - 정상: 세 LLM 합의와 영상 관찰 + 두 LLM 단계 허가 + 운반.
   - 준비 지연: LIFT의 R3 보고 두 번 전달 보류. 두 회 모두 실행 보류하고 새 양쪽 보고 후 재개.
   - 운반 보고 단절: 운반 12~16번째 R3 보고 전달 보류. 양쪽 바퀴 정지 후 새 보고로 재개.

모든 조건은 출발 거리 .6/.6m, yaw 0/0°, lateral 0/0m. 기존 물체·평지·카메라·FOV·외관·
물리/학습 파일/시연 명령과 weld OFF를 유지한다. 평가 값은 제어에 사용하지 않는다.
검증은 운반 참가자와 기술을 고정하며 R2 관찰 시점은 실제 모델 선택으로 기록한다.
모델 응답 차이를 통제한 인과 비교나 반복 성공률 추정이 아니다.

각 조건에서 실행 SHA, 정확한 요청/응답·RGB·발행 명령·원본 해시, 물리 성공, 협상 회수,
정지/재개, 시간·명령 수·모델 요청/토큰·비용 가용성을 기록한다. 실패도 보존한다.
입력과 제어를 원본 바이트에서 재생 감사하고 영상의 접근·파지·운반·놓기를 표본 확인한다.
소스 수정이 필요하면 개발 실패는 남기고 최종 후보에서 3조건 전체를 다시 검증한다.

본실험 범위 밖: 새 운반 조합, 세 대 파지, 별도 화물 동시 운반, 지형 경로, 망/프로세스
장애, 실시간 LLM 추론 지연, 자동 재계획 후 복구, 물체를 든 채 역할 교체, 실물 로봇.
