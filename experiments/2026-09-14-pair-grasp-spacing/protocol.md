## 진단 후 후보 변경

첫 후보의 바퀴 보정만으로는 1500 PWM 파지에서 안쪽 미끄러짐을 막지 못했다. 두 번째 후보는 동일한 모델·물리 설정에서 집게 닫힘 명령만 1700 PWM으로 완화하는 명시적 비교를 추가한다. 1500/1700/1800은 고정 명령 후보이고 접촉력이나 실시간 정답을 제어에 사용하지 않는다. 모델 파일·들어올리기 명령은 유지하며 실제 닫힘 명령의 차이를 보고서와 실행 추적에 기록한다. 기존 'grasp 모델 동일'을 '닫힘 명령도 동일'로 해석하지 않는다.

1700 PWM은 영상 보정 ON/OFF의 짧은 비교에서 모두 최대 간격 변화 0.569 cm, 접촉 상실 0으로 통과했다. 따라서 초기 미끄러짐 개선의 주된 변경은 닫힘 명령 완화이며, 영상 보정의 필수성이나 우월성을 이 비교로 주장하지 않는다. 당시 후보는 1700 PWM과 영상 anchor 감시/보정을 함께 사용하며, 운반 중에도 최초 파지 간격에서 2 cm 이내를 유지해야 통과한다. 해당 실행 버전의 기본 닫힘 명령은 1700이었다.

1700 PWM 전체 코호트(e7708a3)는 초기 간격을 모두 유지했으나 운반은 3/5였다. narrow-door와 staggered-obstacles에서 긴 운반 중 하중이 서서히 내려가 grip_stop에 도달했다. fully-blocked는 정상 정지했다. 다음 진단은 중간 고정 명령 1600 PWM이다. 먼저 같은 초기 파지를 확인하고, 통과하면 narrow-door 긴 운반을 확인한다. 다른 물리·영상·경로 설정은 바꾸지 않는다. 후보 선정 후 같은 SHA의 전체 6개 지형을 다시 실행한다.

1600 PWM 진단(52b84c8)은 초기 간격 변화 최대 0.614 cm, 111개 lift/hold 표본의 접촉 상실 0으로 통과했다. narrow-door도 운반 90.7 SIM초, 전 표본 접촉·lift·간격 유지, 충돌 0으로 내려놓기까지 성공했다. 최종 후보의 기본 명령을 1600 PWM으로 고정한다. 나머지 설정은 동일하다. 이는 이 환경에서 검증할 후보이며 전역 최적값이나 다양한 초기 자세/물체/실물 로봇의 성공을 주장하지 않는다.
