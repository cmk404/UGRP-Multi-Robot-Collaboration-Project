# ㄱ자 자세의 공동 파지 시험

사용자 요청: 몸체는 앞으로 향한 상태에서 팔을 옆으로 돌려, 손잡이 없는 물체 본체를 두 로봇이 잡는다. 인위적 고정 제약은 사용하지 않는다.

설계: 물체는 기존 5 x 45 x 4 cm 직육면체, 0.196 kg. 긴 축은 world Y, 로봇 몸체 전방은 world X, 팔은 각자 +90/-90도로 안쪽을 향한다. 이때 그리퍼 닫힘 방향은 world X가 되어 물체의 5 cm 폭을 끼워 잡는다. 기존 정면 접근은 닫힘 방향이 물체의 긴 축과 같았다.

초기 배치는 분리 시험 fixture이며 자율 접근 검증은 아니다. 시험 중 물체 pose 변경, 추가 손잡이, 인위적 고정, 마찰/질량 조정은 하지 않는다. 실행 SHA와 실제 접촉·상승·유지 결과, 원본 영상 위치 및 해시는 실행 후 기록한다.
