## 변경 내용

- 모델이 정한 장애물 우회 방향과 종료 조건을 로봇 자신의 기억으로 보존한다. 빠진 note나 잘못된 note가 이전 결정을 지우지 않는다.
- 실제 실행된 전진 제어 시간, 회전 방향 변경, 과거 차단 장면과의 유사도를 제공한다. 시간과 픽셀 변화는 거리·통과·안전의 증거로 취급하지 않는다.
- 회전만 한 뒤 전방 차단이 사라졌다면 이전에 차단됐던 동일 로봇 NAV 원본을 비교용으로 제공할 수 있다. 현재 WRIST/NAV는 유지하며 총 이미지는 최대 3장이다. 과거 이미지의 출처·해시·시각을 검증한다.
- 반복 지침을 줄이고 조작 단위·출력 JSON 예시를 명확히 했다. 내부 경계가 잘 안 보이는 `DESTINATION_SQUARE_UNDERCONSTRAINED`를 무조건 추가 전진해야 한다는 뜻으로 해석하지 않도록 했다.
- 초기 집기 접근에서 정면을 향한 중간 정지 위치에 도달했는데도 정확한 waypoint를 쫓다 표적을 놓치는 문제를 수정했다. 기존 0.35m 거리와 0.055m 거리 허용치, 15° 방향 기준으로 중간 단계만 완료하고 최종 bearing·IK·파지 검사는 유지한다.
- 화물의 일부 청록색 면을 윗면으로 잘못 맞춰 낮은 높이를 추정한 경우, 표면 추정과 마커 기반 높이를 구분한다. 표면 추정만 불확실하면 정지하고 `grip_uncertain`을 전달한다. 모델이 `check_grip`을 선택해야 기존의 엄격한 좌·우·원위치 검사를 실행한다. 마커 기반 낮은 높이 중단, 충돌 검사, 내려놓기·완료 조건은 유지한다.

목적지 경로와 우회 방향은 모델이 계속 선택한다. 시드별 고정 경로, 숨은 좌표, 평가용 물리 상태를 모델이나 제어 선택에 제공하지 않았다.

실패 실행을 보존하고 버전별 전체 결과를 계산한다. 다른 버전의 성공만 골라 5/5로 합치지 않는다. 각 실행의 원본 입력, 모델 결정, 실행 명령, 평가 기록, 동영상, 검토 이미지와 판정은 [작업 결과 폴더](../outputs/navigation-generalization-repair-20260908/)에 있다.

E5 직전 검증:

- 의도된 Mac 시뮬레이션 환경에서 관련 테스트 157개 및 subtest 34개 통과. Python 컴파일과 diff 검사 통과.
- 46번 종료 원본 RGB 재입력에서 잘못된 높이 0.0202059m를 재현했고, 수정 후에는 자동 팔 동작 없이 `grip_uncertain`으로 전환됨을 확인했다. 능동 파지 검사의 실제 결과를 이 정지 이미지 재생만으로 주장하지 않는다.
- E3/E4 42번의 원본 손목 사진 359장을 해시 검증하며 재생했다. 새 중간 접근 완료 조건의 첫 충족은 각각 step 73/75이며, 시뮬레이터 물리 상태는 재생 입력에 사용하지 않았다.
- 별도 무모델 접근 검사에서 기존 코드는 지연 1.54초일 때 60.330초 후 표적 손실을 재현했다. 수정 코드는 같은 지연 및 28ms 짧은 지연에서 각각 117.420/117.392초에 접근·집기를 완료했다. 이 세 검사는 운반 성공 횟수에 포함하지 않는다.
- 별도 접근 영상은 전체 디코딩, 시간순 12개 샘플 및 성공 후 최종 손목 원본을 검토했다. 연속 전체 영상 수동 재생과는 구분한다.

E5 전체 검증에서 42번은 접근부터 내려놓기까지 성공했다(활성 SIM 181.012초, 실제 경과 152.647초). `check_grip`이 필요한 상태는 발생하지 않아 능동 파지 검사의 모델 선택 실행은 이번 코호트에서 검증되지 않았다. 다섯 실행의 소스가 동일했고, 관통 충돌은 모두 0초였다. 각 영상은 전체 디코딩 및 시간순 12개 샘플, 모든 모델 NAV 입력과 성공 후 손목 사진을 검토했다.

로컬 호출 프록시를 읽어 확인한 결과 `none`과 `low`는 모두 LOW 추론으로 전달됐다. `medium`은 별도 MEDIUM 모델 설정으로 전달된다. E5 원본 실패 장면의 13번째 요청은 LOW에서 잘못된 좌회전을 반복했지만, MEDIUM에서 우회전으로 바뀌었다. 이 저장 입력 시험은 물리 명령이 없으므로 운반 성공의 증거는 아니다. E6는 이 설정만 바꾸며, 별도로 시험한 추가 프롬프트·과거 전진 이미지·문맥 축약은 적용하지 않았다. 현재 관련 회귀 검사 명령은 143개 테스트 및 28개 subtest가 통과했다.
