# 2026-09-25 구역 화물 인식 v2 (`top_cargo_v2`): 평행 빔 병합·틀 안쪽 상자 수정

## 질문

PR #168(`top_cargo_v1`)의 Codex 적대 검토에서 두 결함이 나왔다.

- **[High]** `_merge_beams()`가 약 4.5 cm 떨어진 서로 다른 평행 빔 두 개를 하나로 합칠 수 있다.
- **[Medium]** tri_frame 삼각형 안쪽에 놓인 상자가 "화물 위 상자"로 억제된다.

새 프로필 `top_cargo_v2`가 이 두 결함을 고치면서 v1이 찾던 것을 잃지 않는지 확인한다. 틀 안쪽 결함은 v1의 held-out test에서 발견됐으므로 **새 dev/test 시드**로 다시 평가한다.

## 범위와 경계

- **입력:** TOP RGB 네 장, 작성된 TOP 보정, 정적 화물 목록(`sim.zone_cargo`)만 쓴다.
- **정답:** 시뮬레이터 자세·분할 정답은 `eval-labels/`에만 있고 검출기에는 전달하지 않는다.
- **장면:** 동기 SIM 렌더, 순간 이동 후 0.6 s 안정화. weld는 OFF이며 카메라·외관은 바꾸지 않았다.
- **제어 미연결:** 검출 정확도만 평가했다. 제어기·프롬프트 연결과 실제 운반 성공은 다루지 않는다.
- **v1 보존:** `harness/zone_cargo_perception.py`는 PR #168 병합본과 바이트가 같다(sha256 `57335d61…`, 테스트로 고정). v1의 과거 test 수치는 v2에 승계하지 않는다.
- **번들:** 실행 번들 레지스트리는 바꾸지 않았다. v2 모듈은 번들 소스 closure 밖에 있다(테스트로 확인).
- **workflow:** `zone-cargo-perception-eval`을 1.0.0에서 1.1.0으로 올렸다. `--split-file` 옵션과 view plan v2를 추가했으며, 기본 경로(v1 split·plan)는 그대로다.

## 수정 내용 (`harness/zone_cargo_perception_v2.py`)

1. **빔 병합(High)**
   - **같은 카메라의 검출은 절대 합치지 않는다.**
   - 다른 카메라끼리도 다음 조건을 모두 만족할 때만 합친다.
     - 각도 차 5° 이하, 측면 거리 2 cm 이하(v1은 5 cm).
     - 축 방향 겹침 -3 cm 이상.
     - 합친 길이가 정적 빔 길이 + 8 cm(0.68 m) 이하.
     - 한쪽의 **보이는(경계에 잘리지 않은) 끝**을 다른 조각이 6 cm 넘게 지나가지 않을 것.
   - 비빔 종류의 시야 간 중복 제거도 다른 카메라끼리만 한다.
2. **한 시야 안에서 붙은 평행 빔 분리.** 가장자리 간격이 3 cm 미만이면 한 시야에서도 두 빔이 한 덩어리가 된다. v1은 이를 폭 초과로 버렸다.
   - v2는 폭이 1.6배를 넘는 덩어리를 윗면 화소 기준 Otsu로 둘로 나눈다. 윗면 화소는 축 방향 3 cm 구간에서 밝기 90분위의 0.85배 이상인 화소다.
   - 두 절반의 평균으로 공통 방향을 3회 다시 추정한다.
   - 결과에 `evidence.split_from_wider_blob`을 표시한다.
   - 폭 0.6배 미만 조각(sliver)은 버린다.
3. **틀 안쪽 상자(Medium).** 상자는 다음 경우에만 억제한다.
   - 틀 **막대 띠** 안: 막대 반폭 + 1 cm.
   - **손잡이 돌기** 중심 4.5 cm 이내.
   - 삼각형 안쪽 빈 곳의 상자는 남긴다. 다른 화물 종류의 억제 규칙(다각형)은 v1과 같다.
4. **변경하지 않은 부분.** 그 밖의 색·모양 판정, 출력 스키마(`ugrp.zone_cargo_perception.v1`), `grasp_handles`는 v1과 같다.

## 회귀와 남은 문제

- **빔 개수 초과 6장면**(v1은 2장면)
  - 중복 4개(신뢰도 0.21–0.47)
    - `s607-robots_on_paint-0`, `s609-parallel_beams-1`, `s610-scatter-0`: 두 번째 시야에서 경계에 잘린 짧은 조각의 방향이 흔들린다. 측면 거리가 2 cm를 넘어 같은 빔으로 합쳐지지 않는다.
    - `s611-straddle-0`: 세 시야에 걸친 빔을 탐욕적으로 묶다가 한 조각이 남았다.
  - 오검출 2개: `s610-paint-1`은 sliver, `s612-box_in_frame-0`은 로봇 위 조각으로 v1도 같다.
  - v2는 서로 다른 빔을 합치지 않는 대신, 같은 빔의 짧은 조각을 덜 합치는 쪽으로 옮겨갔다.
  - 연동 담당에게 권하는 규칙
    - 신뢰도 0.5 미만 빔은 다른 시점에서 다시 확인한다.
    - 같은 축 위 가까운 빔 두 개는 길이 합을 정적 길이(0.6 m)와 비교해 판단한다.
- **합성 테스트의 잔차.** 축 방향 어긋남이 큰(>6 cm) 붙은 쌍에서는 분할된 한쪽이 끝에 3–4 cm를 더 가져간다. 그 결과 중심 오차가 약 13 mm다.
- **v1 한계는 그대로다.** can 서쪽 치우침, 같은 색끼리 닿은 물체, 정지 영상, `zone_wide` 조명 한정.
