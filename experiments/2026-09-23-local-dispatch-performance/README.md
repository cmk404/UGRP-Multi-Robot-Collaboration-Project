# 로컬 dispatch 속도·병렬 실행 검증 — 2026-09-23

표준 MuJoCo 실행에서 느린 RGB 처리와 독립 경로의 불필요한 직렬화를 구분한다. PR #118의 접근 동기화·정지 재관측을 유지하고, 공통 MacroQueue 물리 복구 PR #120과는 결합하지 않는다. [프로토콜](protocol.json)에 동일 계획·모델·물리·영상 조건과 실행 예산을 먼저 고정했다.

표준 `dispatch`는 pair가 소비하지 않는 카메라·개요 촬영을 생략하며, 합의된 open-map 독립 경로에서 기존 동시 운반 경로를 자동 선택한다. 선행 조건·공유 경로/자원·지원하지 않는 맵은 직렬로 유지한다. 기존 하역 구역 독점과 actor 입력 경계는 유지한다. `result.json`과 `skill-bindings.json`의 `overlap_selection`은 적용 여부와 이유를 기록한다. `--full-capture --serial-route`는 이전 조건을 복원한다.

새 소스와 번들을 고정한 뒤 수정 전/후 물리 재생을 각각 최대600초 실행한다. 새 후보의 전체 운반 성공과 동시 적재 이동은 아직 판정하지 않았다. 정적 번들 검사 및 자동 테스트는 물리 성공을 뜻하지 않는다. 완료 후 실패도 포함해 새 원본·해시·TensorBoard를 이 기록에 연결한다.
