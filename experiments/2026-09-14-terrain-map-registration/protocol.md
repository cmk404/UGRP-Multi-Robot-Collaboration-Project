# 예시 지형의 실행용 지도 등록

사용자 요청: 예시 지형을 바탕으로 map에도 지형을 추가한다.
PR #45 head `fc0cd309c72c9116be4e34ae63a538533b07def2`의 6개 예시를
`maps/pair_navigation`과 기존 단독 주행 `maps/navigation`에 등록한다.
원본 실험 파일과 기존 지도 3개는 보존한다. 기존 PR #45에 후속 커밋으로 기록한다.

공동 운반 파일은 원본을 그대로 복사한다. 단독 형식에는 같은 벽·경계·카메라·
시작 구역·목표 중심을 쓰되 기존 단독 footprint, 2.5 cm 격자와 0.18 m 목표 반경을
유지한다. 단독 실행기에 없는 공동 목표 yaw를 임의의 제어 입력으로 변환하지 않는다.

소스를 커밋하고 고정한 뒤 두 기존 장면 생성 경로를 통해 지도를 불러온다.
공동 운반은 `build_pair_terrain_gallery.py`가 `maps/` 카탈로그를 기본으로 읽는지,
6개 원본과 지도·컴파일 벽·카메라가 같은지 확인한다. 단독 주행은
`verify_terrain_maps.py --render`로 6개 장면을 렌더하고 벽 형상·카메라·초기 접촉·
weld OFF를 검사한다. 모든 작업은 소유 세션 래퍼로 실행하고 종료를 확인한다.

기하 경로 계산과 초기 정지 화면만 검증한다. 로봇 주행·파지·운반·LLM 판단은
실행하지 않는다. 실제 성공률은 산출하지 않는다. 새 검증 원본은 새 outputs 폴더에
저장하며 최종 기록에는 소스 SHA, 지도 해시, 환경·비용·검토 범위와 보관 위치를 남긴다.
