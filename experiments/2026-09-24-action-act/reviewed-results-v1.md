## ACT 학습·추론

첫 학습은 8,000회 갱신했고 step 1,500 모델을 선택했다. 개발 에피소드 4/4에서 종료를 누락했고 실제 비교는 0/2였다. 이 가중치와 실행 자산은 [GitHub 비교 모델 Release](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/releases/tag/models-20260924-action-act-v1)에 보존한다. 공개 asset은 기본 제어기 채택이나 물리 성공을 뜻하지 않는다. 새 다운로드·로딩 검증은 배포 기록에서 별도로 확인한다.

두 번째 학습도 8,000회 갱신했지만 원래 엄격한 수치 일치 검사를 통과하지 못해 모델 내보내기가 실패했다. 추가 0-step finalization도 실패했다. 전체 5,062개 입력을 확인한 결과 개발의 23개 첫 행동 done 좌표가 오차 허용치를 넘었고 운동 좌표와 done 이진 판정은 같았다. 수치 허용치를 완화해서 모델을 통과시키지 않았다. 이 모델은 개발 종료 누락 2/4와 조기 종료 2/4도 있어 운반 적격 모델이 아니다.

동일 첫 모델·동일 입력의 ABBA 요청 벤치마크는 순차 추론 대비 두 로봇 병렬 추론과 입력 캐시에서 중앙값 **109.49ms → 38.71ms**였다. 24개 대응 관측, 디코딩된 행동 차이 0, done 동일이다. 이는 요청 지연 64.6% 감소이며 카메라·물리를 포함한 전체 임무 속도는 아니다(`runtime-benchmark-comparison.json`).

## 입력·소통·보존

모든 표의 실험은 저장된 계획을 재생했으므로 **새 자연어 메시지는 0개**다. 실제 에이전트 대화의 효과를 비교한 결과로 해석하지 않는다. 대화 관찰기는 저장 재생과 실제 메시지를 구분한다.

카메라/FOV·물리 조건·weld OFF를 유지했고 정답 평가는 제어 입력에서 분리했다. 성공과 실패의 raw, 영상, 입력·모델 요청을 로컬에 보존한다. TensorBoard 신규 변환과 실제 화면 검증은 아직 이 기록의 완료 범위에 포함하지 않는다. 관련 논문 검토는 `literature-review.md`이며 구현하지 않은 논문의 성능을 현재 시스템 성능으로 인용하지 않는다.
