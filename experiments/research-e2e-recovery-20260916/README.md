# 역할 합의·오류 복구·접근 실행 수정 결과

**역할안 진동과 일회성 모델 오류 중단을 고쳤고, 실제 접근은 개선됐다.
전체 파지·운반 E2E 성공은 아직 0/2다.** 최종 natural/none 모두 PREPARE에서
입력 토큰 예산으로 끝났으며 양쪽의 영상 기반 파지 준비 보고는 나오지 않았다.
GRASP 이후 단계는 이번에도 실제 검증하지 못했다.

이 작업은 창민의 동기화/실행 연결 범위다. 기존 학습 모델은 교사가 배치한
파지 초기 자세와 시연 재생 조건에 묶여 있어 이번 자율 접근 경로에 바로
연결하지 않았다. RGB→원시 명령 임시 actor와 보수적인 로컬 이동 adapter를
사용한 파일럿이며, 팀원의 최종 고수준·로봇 로컬 정책 통합 완료가 아니다.

## 수정과 확인

| 이전 병목 | 수정 | 실제 확인 |
|---|---|---|
| 서로의 직전 제안을 따라 역할안을 동시에 바꿈 | 제안권 순서, 단일 역할안·해시 고정, 양쪽 동일 버전 ACK | 최종 natural 3턴, none 2턴에 합의; 배정 내용은 모델이 결정 |
| 타임아웃/잘못된 JSON 한 번에 전체 종료 | HOLD 상태에서 실패한 요청만 최대 3회 재요청, 요청 ID로 응답 구분 | 진단의 형식 오류 2건, 최종 natural의 실제 타임아웃 2건 모두 복구 |
| .2초 이동마다 LLM 호출 | 직진 의도를 새 TOP 영상으로 검사하며 최대 10개 임대로 실행 | natural에서 r1/r3 37.60/33.84cm 이동, 30요청 |
| 앞 로봇의 잔여 움직임 때문에 다음 로봇의 영상 이동 식별이 모호함 | HOLD 후 두 연속 영상 구간의 안정 확인, 제한 시간 내 불충족이면 미발행 | 최종 두 실행의 48개 대기 구간 모두 이미지 정지 기준 충족; 로컬 혼합 움직임 중단 0 |

회전·곡선은 한 임대 뒤 모델에 반환한다. 로컬 adapter는 이전 모델의 의도만
갱신하며 새 경로, 집게 정렬, READY/DONE을 만들어 내지 않는다. 근접·대상 손실·
새 움직임 미확인·진행 정체·예산 종료 때 멈춘다. 각 임대 명령은 자기 이력에
별도로 남는다. 두 로봇의 접근은 영상 이동 식별을 위해 순차 실행한다.

## 모든 실행

최종 후보는 `ae51834795330c347e885dc2a83ad457ef29f5c9`다. 두 조건을 실행하는 동안
소스를 바꾸지 않았다. 최초 `f00a79904458cdd5ac8d046135583888a0c15509` natural은
잔여 움직임 문제를 찾은 진단이며 대체하거나 숨기지 않았다.
사전 조건과 수정 경위는 [protocol.md](protocol.md), 환경·설정·오류·원본 해시는
[results.json](results.json)에 있다.

| 실행 | 합의 턴 | 요청 | 벽시계 | 명령 r1/r3 | 이동 r1/r3 | 종료 |
|---|---:|---:|---:|---:|---:|---|
| 최초 진단 natural | 2 | 28 | 154.8초 | 35/11 | 32.97/1.12cm | PREPARE, 토큰 예산 |
| 최종 natural | 3 | 30 | 166.7초 | 25/29 | 37.60/33.84cm | PREPARE, 토큰 예산 |
| 최종 none | 2 | 30 | 196.0초 | 34/22 | 35.83/18.91cm | PREPARE, 토큰 예산 |

이동은 평가 출력에서 계산한 시작 대비 평면 변위이며 이동 거리의 누적합이나
파지 자세 도달 판정이 아니다. 기존 natural-repeat는 32요청·165.2초에
8.56/7.44cm였다. 이번에는 비슷한 벽시계·요청 수에서 더 이동했지만 초기 표본과
조건당 1회 결과의 설명적 비교다. 통신 ON/OFF의 우열이나 성공률 개선을 주장하지 않는다.

최종 natural/none의 보고 입력 토큰은 각각 186,428/193,438이다. 180,000은 새
요청 시작을 막는 soft cap이므로 진행 중인 두 요청이 경계를 넘을 수 있다.
natural 타임아웃 2개의 usage는 누락됐다. 금액은 제공되지 않아 null이며
누락된 호출을 무료로 계산하지 않는다. SIM은 모델 대기 중 멈추므로 영상은
모델 대기 시간을 압축한 물리 시간이다. 실물 비동기 지연 검증이 아니다.

## 남은 첫 미통과 단계와 역할

첫 미통과 조건은 **PREPARE의 두 로봇 모두 `at_grasp_pose + stopped`를 영상으로
확인하는 것**이다. 최종 두 실행에서 이를 보고한 로봇은 없었고, 실제 손가락 접촉,
빔 상승 및 목표 구역 이동도 없었다. 준비 판정을 중앙에서 대신 채워 GRASP로
넘기지 않았다. natural 마지막 자기 영상에서 r1은 빔이 시야 밖이고 r3은 빔이
우하단에 치우쳐 있었다. 현재 raw actor가 작은 회전과 팔 조정을 반복하는 동안
예산이 소진됐다. 예산 증가만으로 성공할지나 이후 단계의 병목은 아직 확인되지 않았다.

1. **로봇 로컬 담당:** 현재 시작 분포에서 영상만으로 접근·집게 정렬을 수행하고,
   새 관측에 근거한 READY/진행/불확실 보고를 제공하는 실행기를 검증한다.
   교사 초기화 모델/시연 재생 성공과 학생의 독립 새 조건 실행을 구분한다.
2. **동기화 담당:** 검증된 실행기를 지금의 작업 ID·HOLD·짧은 명령 임대·관측 보고
   경계에 연결하고, 취소/지연/실패를 포함한 공동 GRASP부터 전체 단계까지 다시 실행한다.
   현재 adapter는 그 연결을 진단하는 구현이며 범용 로컬 기술을 대신하지 않는다.
3. **고수준 담당과 공동:** 도달 가능한 로컬 기술을 바탕으로 역할·목표·재계획을
   검증한다. 평지 파지·운반이 통과한 뒤 적재 지형/3대 혼합 작업을 확대한다.

## 검증과 원본

- 로컬 회귀 **697 tests + 154 subtests** 통과. 교차/오래된 ACK, 제안 거절,
  타임아웃→형식 오류→정상 복구, 재시도 소진, 요청 ID, 정지 영상, 복수 움직임,
  대상 손실, 근접 반환, 곡선 임대 제한을 포함한다.
- 3회 총 **88개 실제 wire 요청·340개 이미지 참조**를 해당 source SHA로 재구성했다.
  자기 명령/자기 제안/상대 메시지/동일 관측 재시도의 출처를 확인했다.
- **145개 로컬 RGB 판단**과 최종 실행의 영상 안정 확인을 저장된 JPEG로 재생했다.
  평가용 정답이 제어 입력으로 흐르지 않는 신뢰된 로컬 호출 경계와 정확한 본문
  일치 감사다. 프로세스 격리나 모델의 시각 판정이 옳다는 증명은 아니다.
- 카메라 위치/FOV·형상 불변, weld OFF, 정리 오류 없음. 이번 세션은 모두 종료했고
  기존 프록시는 그대로 두었다.
- 최초 진단 영상 96프레임 중 8개, 최종 natural 143개 중 12개,
  최종 none 155개 중 12개를 전 구간에 분산해 직접 검토했다. 별도 평가 시계열은
  전체를 집계했다. 전 프레임 육안 검토로 표현하지 않는다.
