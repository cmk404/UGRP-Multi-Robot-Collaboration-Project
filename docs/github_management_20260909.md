README를 현재 구현/검증 인덱스로 바꾸고 초기 연구 브리프는 보관했다. CONTRIBUTING.md와 AGENTS.md에 PR·검증·실험 기록 절차를 정리했다. GitHub Actions는 Python3.12에서 외부 모델이나 하드웨어 없이 포터블 회귀검사 188개와 세부검사107개를 실행한다. 별도의 깨끗한 로컬 환경에 requirements-test.txt만 설치해 동일 검사를 통과했다.

기존 실행 환경 검사만으로는 의존성 누락을 알 수 없어 깨끗한 환경도 확인했다. 실험 환경의 설치 버전은 별도 기록했으며 CI 환경과 동일하다고 주장하지 않는다.

영상·raw로그·가상환경·중복ZIP·개인 설정은 로컬에 보존하고 제외했다. GitHub에는 설정·결과·환경·원본 식별값과 작은 회귀 fixture를 저장한다. raw 원본의 원격 백업은 아직 없다. 과거 진단 재생 도구의 로컬 원본 의존성과 미검증 부분을 CONTRIBUTING.md에 명시했다.

남은 관리·성능 과제는 GitHub 이슈에서 추적한다. PR/병합/CI의 최종 상태는 GitHub가 권위 있는 기록이다.

첫 GitHub CI에서 과거 테스트의 로컬 outputs 의존성이 드러났다. 새 Python 환경 테스트도 같은 작업 폴더를 사용했기 때문에 이를 발견하지 못했다. 필요한 최소 영상·PWM을 포터블 fixture로 보존하고, outputs가 없는 git archive checkout에서 188개+107개 검사가 0 skipped로 통과했다. 결과와 실제 CI 상태를 구분해 기록한다.
