## 2026-09-25 (2) — 주 연구 조건 변경

- **결정:** 조정 조건을 "통신 없음 / 동적 통신 / 미리 계획(`plan_first`)"에서
  "**통신 없음(`independent`) / 동적 통신(`dynamic`, 분산 한국어 대화) / AI 한 명이 모두
  지휘(`leader`, 중앙 지휘)**"로 바꾼다.
- **이유:** "`plan_first`(제안자 순환 + 만장일치 ACK)는 협상 프로토콜의 변형일 뿐 연구 조건이
  아니다. `leader`와 `dynamic`의 비교는 같은 대화라도 중앙 지휘 구조와 분산 구조의 차이를 본다."
- **`plan_first` 은퇴:** 새 본 연구 조건에서 뺀다. "다만 Z1–Z3·ZC1·ZC2 재현을 위해 코드는
  남긴다." 기존 기록과 결론은 기록 당시 조건 범위 그대로 유지한다.
- **상태:** "아직 이 세 조건으로 실행한 결과는 없다."

## 2026-09-25 (3) — 후속 방향 갱신 (같은 날, 조건 4개로)

같은 절의 "후속 방향 갱신"에서 조건이 넷으로 늘었다. 위의 세 조건 목록은 기록 당시 결정으로
그대로 두었다.

- **주 비교 축:** "통신 채널만 바꾸고 나머지(지도·작업·로봇·물리·입력)는 모두 같게 둔다."
  조건은 무통신 / 자유 한국어 동료 대화 / 한국어 명령 지휘자(`leader`) / 정형 메시지 통제다.
  "정형 메시지 통제 조건은 같은 정보를 고정 스키마로만 주고받게 해서, 자연어의 효과와 정보
  공유의 효과를 분리한다. 모든 로봇의 카메라를 보는 전지적 지휘자는 주 조건이 아니라 참고용
  상한으로 따로 둔다."
- **로봇 입력 변경:** "공용 TOP 카메라를 로봇 LLM 입력에서 뺀다. TOP 영상은 평가·채점용으로만
  남긴다." 대신 정적 지도와 작업 지시서를 매 호출에 준다. "작업 지시서는 반드시 시나리오
  설정에서 만들고, 시뮬레이터 상태에서 만들지 않는다."
  사용자 원문: "정적 지도도 계속 llm이 볼 수 있게 … 실제 지도를 보면서 일하듯이 대신 실시간
  상황은 못 보고".
- **대화·사고 시간 비용:** "말하고 생각하는 시간도 SIM 시간을 소모해야 한다. 소모 모델은
  앞으로 설계한다."
- **이유:** "위에서 내려다보는 카메라가 있으면 로봇은 말하지 않아도 모든 상황을 알 수 있다.
  그러면 대화 효과는 0에 가깝게 나올 가능성이 크다. 참고한 선행연구는 Chen et al.,
  ICRA 2024(arXiv 2309.15943)와 Guo et al., 2024(arXiv 2403.12482)다."
- **알려진 공백:** "로봇 자기 카메라만으로 하는 인식이 아직 없다."

## 2026-09-25 (4) — 지휘자 형태 결정 (사용자 승인)

- "로봇 한 대가 지휘자를 겸한다. 지휘자는 고정하지 않는다. 시행·시드마다 r1/r2/r3로 돌려서,
  누가 지휘자인지와 그 위치의 영향을 상쇄한다."
- "통신은 지휘자 ↔ 각 추종자만 잇는 허브-스포크 구조다. 추종자끼리는 직접 대화하지 않는다."
- "지휘자는 작업 배정, 팀 운반 역할, 좁은 문 통과 순서를 정한다."
- "추종자는 지시를 따르되, 막힘이나 파지 실패 같은 상황은 한국어로 보고하고 이의를 제기할
  수 있다."
- "지휘자는 시작 시, 보고를 받았을 때, 누군가 할 일이 없어졌을 때 호출된다."
- 이유 셋: "첫째, LLM 수와 각 LLM의 입력이 다른 조건과 같아서 통신 채널만 다르다. 둘째,
  지휘하는 시간만큼 지휘자 자신의 작업이 늦어지므로 현실적인 병목이 생긴다. 셋째,
  Guo et al. 2024의 지정 지휘자 설정과 맞는다."
- "별도 지휘 AI 방안은 전지적 참고 상한으로만 남긴다."
