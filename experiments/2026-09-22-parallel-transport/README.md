# 2+1 concurrent transport revalidation

Open-map independent north/south routes. Box grasp begins after the pair issues its first loaded-motion command; the box queues at an RGB-observed staging point before the shared bay. Original calibration, cameras, physics and model weights are fixed. Explicit task dependencies are never removed at runtime. Cluttered moving-obstacle rotation is outside this candidate.

The protocol contains two reference validation trials, not a failure-rate cohort. Result records and video review will be added after completion. ACT128 input-model comparison runs separately with original serial scheduling to isolate calibration from scheduling.
