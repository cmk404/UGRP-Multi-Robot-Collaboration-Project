# ACT 운반·방출 연결 및 기준선 재검증

2026-09-22 사용자 요청으로, 교사 성공과 ACT 전체 실패 사이의 실행 차이를 고친다. 이 문서는 실행 전 계획이며 수정 후 물리 성공을 주장하지 않는다.

- ACT가 raw TOP RGB를 읽을 때 빔 추적 상태도 갱신해 기존 내려놓기 경로로 전달한다. 모델 입력은 기존 raw 영상·정적 작업·자기 명령 이력이고, 추적 좌표를 ACT 입력이나 조향 보정에 전달하지 않는다. 영상에서 추적을 잃으면 기존 RGB 추적기가 오류를 반환하며 정답으로 보정하지 않는다.

- 원 성공 ACT seed18 체크포인트와 당시 접근/파지 보정 11개 JSON 해시를 검증한다. open-minus에서 RGB 교사와 원 ACT가 먼저 재현되어야 교차로 교사와 기존 RELEASE 실패 사례를 추가 실행한다. 실패 시 원인을 재진단하며 잘못된 기준선으로 대규모 비교를 시작하지 않는다.
