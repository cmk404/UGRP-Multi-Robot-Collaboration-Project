# 세 로봇 실제 운반 검증

관련 이슈: #50. 이전 #62의 R2 정지 관찰은 세 대 운반이 아니다.

목표: 세 에이전트가 물체/목적지/작업 담당을 포함한 동일 계획에 합의한 뒤,
R1/R3는 빔을 녹색 구역으로, R2는 작은 상자를 선택한 자홍색 구역으로
실제로 접근/파지/운반/방출한다. 로컬 기능은 고정된 두 작업 레인용이다.
지원되지 않은 로봇 조합과 임의 경로는 거절하며 일반 작업 할당으로 주장하지 않는다.

새 물체는 기존 small_box_01 형상/질량/마찰/외관을 그대로 사용한다.
정적 장면 초기 배치만 추가하며 정책 카메라/FOV와 기존 로봇/빔은 유지한다.
제어: own RGB + 공용 TOP RGB + 자기 발행 명령. 평가 좌표는 출력 전용.
모든 인위적 weld OFF. 단독 기능의 영상 추정/고정 보정값은 정답 상태가 아니다.

코드 커밋 후 진단을 실행하고 실패를 보존한다. 최종 코드에서 fixture 연결,
실제 LLM auto 목적지 선택, 실제 LLM far 목적지 지시를 각각 검증한다.
물리 판정: 두 물체 모두 들린 상태 이동, 방출, 목적지 안에서 1초 이상 안정.
세 로봇 변위 및 실제 동시 움직임 구간을 별도로 기록하고 영상으로 검토한다.
시간/행동 수/토큰/미보고 비용, SHA/설정/원본 해시/검토 범위를 함께 보존한다.
