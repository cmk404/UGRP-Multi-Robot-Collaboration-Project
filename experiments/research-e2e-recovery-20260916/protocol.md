# E2E 병목 수정 검증

## 범위와 사전 판정

PR #57의 임시 독립 RGB actor를 유지하고 동기화/실행 연결을 수정한다.
팀원의 최종 상위 계획기·학습된 로컬 파지 정책 통합 완료를 뜻하지 않는다.
기존 결과는 `../research-e2e-20260916/`에 그대로 보존한다.

- 역할: 회전하는 제안권 → 하나의 역할안·해시 고정 → 양쪽의 동일 버전 ACK.
  역할 내용은 모델이 결정하며 중앙에서 불일치한 답을 정답으로 고치지 않는다.
- 오류: 로봇을 HOLD한 동일 관측에서 해당 모델만 최대 3회 요청한다.
  시도별 request_id, 원문, 오류, 지연, 토큰을 보존한다. 유효 응답 이후에만
  명령을 발행하고, 예산 초과/복구 불가면 HOLD로 종료한다. 재시도는 동작 재실행이 아니다.
- 접근: 모델의 PREPARE drive 의도를 최대 10 × 0.2초로 실행한다.
  상대를 HOLD한 구간에서 매회 새 TOP RGB의 국소 움직임·주황 보·간격을 확인한다.
  모호함/영상 변화 없음/대상 손실/근접/진행 정체/예산 소진 때 반환한다.
  RGB guard는 파지 자세 판정·READY·새 경로·파지 매크로를 생성하지 않는다.
  매 발행 명령을 자기 이력에 남긴다. 이 방식은 두 로봇 연속 접근이며 병렬 로컬 제어가 아니다.

새 source SHA를 커밋하고 고정한 뒤 natural/none 각각 1회 수행한다.
초기 scene, seed=11, 두 고정 카메라, 외관, weld OFF, Gemini 3.8 Flash,
temperature=.2, max_tokens=900은 기존 pilot과 같다.
동작 최대 40턴, 협상 6턴, 입력 토큰 soft cap 180,000, 벽시계 soft cap 600초,
요청 timeout 30초. 진행 중인 호출은 예산 경계를 넘을 수 있고 누락 usage는 0비용이 아니다.
모델 추론 중 SIM은 멈춘다. 실제 시간 비동기 로봇 안정성 시험은 아니다.
none은 자연어 메시지만 차단하고 구조적 역할 합의는 공통으로 유지한다.

오류 주입 테스트는 타임아웃→형식 오류→정상 응답, 오래된 request/ACK,
제안 거절과 변경, 재시도 소진, 복수 영상 움직임, 대상 손실, 근접 정지를 검사한다.
실제 시험은 역할 합의 횟수, 재시도 복구/소진, 발행 동작 수, 이동량,
도달 단계, 지연/토큰, 물리 성공을 모두 기록한다. 기존 2회씩의 결과와는
설명적 비교만 하며 통신 효과나 일반화된 성공률을 주장하지 않는다.

평가는 별도 출력에서만 참조한다. 관측·발행 명령·모델 peer claim·합의 버전의
출처와 실제 wire 요청을 재구성하고, 로컬 guard의 판단을 저장 JPEG로 재생한다.
카메라/형상 불변과 weld OFF를 확인한다. raw 영상·로그는 outputs/ 로컬 보관이다.
영상도 직접 검토하며 전체 파지·운반 성공과 접근 개선을 구분한다.
