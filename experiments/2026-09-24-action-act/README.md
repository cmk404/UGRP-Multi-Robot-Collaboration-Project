# 액션 알고리즘과 ACT 재학습 — 2026-09-24

사용자 요청: 액션 알고리즘을 바꾸거나 ACT로 학습하고, 짧은 동작 확인을 넘어 의미 있는 결과가 나올 때까지 검증한다.

이전 v26은187.949초 완주 후 같은 소스 반복에서 상자 TOP RGB 추적 실패로 중단했다(1/2). 이번 연구는 상자 가림 시 검증된 자기 로봇 영상 이동과 현재 자기 영상 파지 확인을 함께 사용하는 액션 경로와, 실제 성공 시연으로 재학습한 ACT 빔 운반을 비교한다. ACT가 상자 제어기까지 학습했다고 표현하지 않는다.

현재 단계는 구현·데이터 준비다. 아직 새 모델 학습이나 새 물리 성공을 보고하지 않는다. 제어 입력은 자기 RGB·공용 TOP RGB·자기 발행 명령·허용 정적 지도/작업이며, 평가 정답은 제어에 쓰지 않는다. 가림을 이유로 카메라나 외형, weld OFF, 물리·파지·도착 기준을 바꾸지 않는다.

- 알고리즘 회귀: 검사에 사용된 v26 실패 구간은 개발 회귀이며 미관측 시험이 아니다.
- ACT 데이터: 성공 시연만 입장시키고 실제 최초 발행 명령과 판단을 맞춘다. 갱신 행은 새 교사 판단으로 중복 학습하지 않는다. split은 전체 에피소드 단위이며 해시·원래 소스 SHA를 기록한다. 기존 손실된 development 원본은 제외 사유를 기록하고 복구됐다고 표시하지 않는다.
- ACT 실행: raw RGB와 모델 입력은 유지하고 관측/추론 중 물리를 owner에서 진행한다. 원 관측+0.6 SIM초·개별 최대0.25초 lease·최소0.2초 판단 주기, stale HOLD와 재관측을 적용한다. 채택하지 않은 추론 요청도 기록/집계한다. learned와RGB 종료 확인/최종 보정 조건은 구분한다.
- 비교 설계: `evaluation-design.json`. 기존 검사에 쓰지 않은 새 초기 위치 두 조건에서 기준 RGB/새 RGB/새 ACT를 비교하고 모든 실패·미실행을 분모에 남긴다. 같은 지도 근방 조건이므로 광범위한 일반화 주장이 아니다. 속도는 전체 임무를 성공한 대응 조건끼리 비교한다.

실행 예산·자원은 `protocol.json`으로 고정하고 소스 커밋 및 실행 번들 검증 후 실행한다. 학습과 물리 시험은 동시에 돌리지 않는다. 실제 학습/물리/검사 결과와 모델 배포 링크는 완료된 원본에 연결해 추가한다.
