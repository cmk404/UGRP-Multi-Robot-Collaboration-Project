# Markerless N7 검증 기준 — 2026-09-09

## 남은 문제

성공률과 효율은 별개다. 45번은 접근에 약94초(짧은 이동84회+팔 자세 명령84회), 운반에 약92초(모델 주행 판단17회)를 썼다. 접근 보정 반복과 주행 분할을 개선할 때 이 버전을 비교 기준으로 사용한다. 다섯 시드에 반복 튜닝한 결과로, 새 시드·조명·색·실물 로봇의 일반 성능을 입증하지 않는다.

## 재현

[개발·검증 절차](../../CONTRIBUTING.md)를 따른다. 실험은 유료 모델 호출을 사용하며 CI에서 실행하지 않는다. 기존 기록의 raw 영상·로그는 `outputs/markerless-improvement-20260909/n7/`에 로컬 보관돼 있고 GitHub에는 포함하지 않는다. 포터블 회귀 영상은 `tests/fixtures/`에 별도로 포함한다. 재실행 시 확률적 모델 응답과 요청 지연으로 경로·성공 여부가 달라질 수 있다.
