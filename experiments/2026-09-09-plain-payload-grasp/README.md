# 손잡이 없는 물체의 공동 파지 재시험

사용자 수정 요청: 별도 손잡이를 만들지 않고 같은 물체의 본체를 두 로봇이 직접 잡는다.

앞선 PR #9의 시험은 돌출된 전용 손잡이를 사용했다. 그 결과는 손잡이 없는 물체의 공동 파지 성공을 입증하지 않는다. 이 시험은 본체의 직육면체 형상을 사용하고 실제 본체-손가락 접촉으로 파지를 확인한다.

초기 로봇 배치는 시험 fixture이며 실행 중 물체 pose를 직접 변경하지 않는다. 실제 접촉 확인 후 사용하는 고정 제약은 마찰 파지나 실물 하드웨어 성공과 구분한다. 시험 결과, 코드 SHA, 원본 위치와 해시는 실행 후 이 폴더에 기록한다.
