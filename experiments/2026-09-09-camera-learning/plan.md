# 행동 기억·영상 이력·동작 학습 비교 계획

요청: 세 기능을 모두 적용하고 단점까지 실제로 비교한다. Issue #30, PR #24의 후속 실험이다.

## 유지 조건

기존 `run_camera_pair_transport.py`의 카메라 위치·화각·해상도·물체·마찰·초기 fixture를 유지한다. 집게가 보이도록 장착 카메라나 외관을 바꾸지 않는다. 각 정책의 외부 관측은 해당 로봇 자기 RGB와 공용 상단 RGB뿐이다. 각자 발행한 명령은 내부 이력이며 실제 관절 상태 또는 실행 성공으로 표현하지 않는다. 동료의 명령이나 평가 정답은 학습에도 사용하지 않는다. weld OFF 유지.

## 탐색 비교

같은 커밋 SHA, seed 11, Gemini 3.8 Flash, 로봇당 30판단, task grasp. 조건은 baseline → memory → temporal → learned의 누적 변경이다. 조건별로 정책과 학습 데이터를 초기화한다. 학습 조건에 비교 조건의 데이터를 미리 제공하지 않는다. 4조건 총 최대 240모델 요청. 각 호출 시간제한 45초, 숨은 재시도 없음. 호출 수보다 토큰·지연·실제 행동을 함께 비교한다. 실제 비용은 제공자가 요금을 반환하지 않으면 미확인으로 기록한다.

- baseline: 기존 현재 영상 두 장만 사용하는 정책.
- memory: 최근 자기 명령 이력 추가.
- temporal: 이전 자기/상단 영상 한 쌍 추가.
- learned: 허용된 전후 RGB와 자기 명령의 전이로 갱신되는 작은 온라인 영상변화 예측 모델 추가. 정밀 파지 정책 사전학습이나 물리 정답 학습으로 표현하지 않는다.

진단 후 코드를 바꾸면 새 SHA의 새 코호트로 구분한다. 이 탐색 비교는 한 seed이며 유의성이나 일반 성공률을 주장하지 않는다. 결과에서 반복/오류가 드러나면 의미 있는 원인을 좁히고 필요한 추가 검증을 별도로 기록한다.

## 평가와 단점

모델 입력 경계는 실제 wire body를 원본 RGB와 이전 자기 명령으로 재구성하여 검사한다. 학습 출력도 동일 자료에서 재구성한다. 평가 로그는 감사기·정책이 읽지 않는다.

성공: 양 로봇의 양쪽 손가락 접촉 + 3cm 상승 + weld OFF 2초 유지. 평가값은 예산 종료 뒤 결과에만 반영한다. 성공 외에 반복 명령 길이, 팔 조절/닫기 시도, 왕복 명령, 영상 무변화, 토큰, 모델 지연과 wall time, 학습 데이터 양 및 불확실성을 비교한다. 영상에서 실제 움직임·충돌·접근 실패·파지 여부를 검토한다.

예상 한계: 발행 명령과 실제 자세 차이, 제한된 시야, 적은 학습 표본, 동료/물체 움직임에 따른 학습 혼입, 행동 범위 밖 예측, 늘어난 문맥 비용. 추론 중 물리는 정지하므로 실시간 하드웨어 지연 영향은 검증하지 못한다. 전체 raw 로그와 영상은 outputs의 로컬 보관이며 원격에는 검토 기록·평가·대표 입력 및 해시를 보존한다.
