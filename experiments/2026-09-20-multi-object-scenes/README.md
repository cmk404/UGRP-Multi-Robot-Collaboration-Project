## 시각 검토와 한계

[TOP 전체 보기](qa/top-overview.jpg), [r1](qa/r1-overview.jpg), [r2](qa/r2-overview.jpg),
[r3](qa/r3-overview.jpg)의 12조건 contact sheet를 모두 검토했다. 고정 자기 시점은 초기 주차 위치에
따라 물건을 못 보거나 봉 일부만 보여 주며, 이를 해결하려고 카메라를 옮기지 않았다.
v3 검토 후 최종 v4의 실제 RGB 48개가 바이트 단위로 동일함을 확인했다. 초기 staging TOP,
최종 8개 물건 TOP과 staging 도면은 원본 해상도로도 확인했다. 모든 개별 자기 영상을 원본
해상도로 확대 검토한 것은 아니다. [검토 기록](visual-review.json)에 범위를 남겼다.

같은 재질도 조명/위치에 따라 영상 색조가 달라진다. 외관 서명이 같다는 사실은 RGB 인식이나
동일 외관 물건 ID 추적의 성공을 뜻하지 않는다. segmentation ID는 평가에만 사용한다.
정적 TOP의 높은 가시 비율도 접근 중 가림·물건 교차·재적치 후 ID 유지를 보장하지 않는다.

접근 검사는 매번 주차점에서의 독립 도달성이다. 이전 작업 종료 위치에서 시작하는 연속 로봇
경로, 담당자가 동시에 접근하는 충돌 회피, 미하중/하중 전이, 팔 공간·접촉 파지, 실제 통로
예약/재계획은 미연결이다. 현재 평행 이동 후보와 90도 회전 probe 결과를 반드시 구분한다.
