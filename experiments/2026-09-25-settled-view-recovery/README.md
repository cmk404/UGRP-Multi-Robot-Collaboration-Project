# 정지 후 새 RGB 재관측 후보 v46

v43 진단 1은 15.715초에 `anchor_stale_or_wheel_issued`로 종료했다. 강한 기준 영상(frame 92)은 0.536초 전이었지만, 정상 회전 명령과 갱신 82건 뒤 frame 97을 움직이는 중에 촬영했다. v43은 이 상황을 즉시 복구 불가로 처리했다. 원본과 닫힌 코호트(1회 시작, 7회 미실행)는 보존한다.

v46은 약한 직접 cyan 관측에서 바퀴를 정확히 HOLD하고, HOLD 뒤 0.2초 이후 새 공용 TOP·자기 RGB를 촬영한다. 새 영상이 기존 신뢰도 0.75를 만족하면 기존 주행 허가 검사로 돌아간다. 여전히 약하면, 최근 강한 영상과 두 약한 영상의 색·형상·위치 추정 연속성이 유지되는 경우에만 제한된 카메라 자세 탐색을 한다. 예전 기준 영상의 시간·프레임·바퀴 명령 세대는 수정하지 않는다. 예전 카메라 PWM은 탐색할 자세이며, 현재 관절이나 이동 성공을 뜻하지 않는다.

한 복구는 최초 HOLD부터 4초, 최대 3개 자세이며 전체 최대 3회다. 주행 재개에는 새 강한 영상이 필요하다. 기존 RGB TTL 0.6초, 발행 lease 0.25초, 결정 600회, 카메라·물리·weld OFF는 유지한다. 같은 JPEG 바이트라도 HOLD 뒤 새 프레임으로 촬영한 약한 영상은 재관측에 쓸 수 있지만, 그 자체로 주행 허가나 신뢰도 향상으로 바꾸지 않는다. 자세 변경 후에는 기존처럼 바이트도 달라진 새 영상이 필요하다.

`tests/fixtures/settled_view_recovery/`는 v43의 실제 강한/약한 두 자기 영상을 해시와 함께 보존한다. 테스트에서 만든 미래 시간·프레임은 가상 경계 검사이며 물리 복구 증거가 아니다. 전체 source·bundle·입력·프로토콜을 고정한 후 새 원래 위치 진단 2회, 성공 시 인접 위치 비교 6회를 진행한다. 정적 검사나 이전 실행의 성공을 이 후보에 승계하지 않는다.

번들 `rgb-standard-dispatch-v46`, workflow `1.46.0`. v44는 Claude 동적 협업, v45는 다른 참여자의 계획/전달 작업이 사용한다고 공유되어 건너뛰었다. 실제 물리 결과는 아직 없다.
