# 차체를 돌린 뒤 전진하는 지도 주행

요청: 옆으로 미끄러지는 주행 대신, 길 쪽으로 고개/몸을 돌린 뒤 앞으로 이동한다.
기존 #36 사전 지도 경로 위에 쌓는 변경이다. main에는 사용자 승인 없이 병합하지 않는다.

## 실행 전 비교 계획

- 기존 `holonomic`은 수정 없이 유지한다. `heading`은 영상으로 방향을 추정해 차체를 실제로 회전하고, 양의 전진만 사용한다. lateral 명령은 보정 중에도 0이다.
- 두 조건에 동일한 사전 지도, 로봇, 시작 위치/방향, 고정 카메라, 접은 팔, 물리 환경을 적용한다. 학생은 자기 RGB·공용 top RGB·사전 지도·자기 발행 명령만 받는다. 위치와 방향은 top 영상으로 추정한다. 자기 RGB는 보관하지만 제어에 쓰지 않는다.
- 목표는 빈 코스와 교차 벽 우회에서 충돌 없이 도착, 좁은 통로 거부, 옆걸음 없는 전진과 실제 회전이다. 사람처럼 보이는 정도는 영상으로 검토한다. 속도 향상은 미리 주장하지 않는다.
- 개발은 r1, 시작 [-0.5,-2.55], yaw 0에서 수행한다. 별도 고정 명령 회전 진단은 항법 성공으로 세지 않는다.
- 최종 비교는 이전 개발에 사용하지 않은 두 시작 설정 r1 [-0.48,-2.50], yaw +12와 r3 [-0.54,-2.59], yaw -12에서 open/slalom/narrow × heading/holonomic = 12실행이다. 이 시작 설정은 이전 #36 평가에 사용되었으며 새로운 환경 일반화 증거로 과장하지 않는다. 두 조건 모두 최대 400결정.
- 후보 코드를 먼저 커밋하고 한 코호트 동안 고정한다. 실패를 삭제하지 않으며 모든 실행 SHA, 원본 위치와 해시를 남긴다.

## 검증

- 기존 별도 평가기의 실제 도착, 전 물리 단계 장애물 접촉·weld OFF, 지도 내 footprint, 직립과 카메라/외관 불변 조건을 그대로 적용한다.
- 입력 원본을 재생하여 모든 결정이 일치하는지 감사한다. 기존 style 필드 없는 기록은 holonomic으로 해석한다.
- 회전과 이동 방향 오차는 실행 종료 후 평가 기록에서만 계산한다. 실시간 제어에 사용하지 않는다. 전진 이동의 방향과 차체 방향 차이를 거리 가중으로 비교하고, 회전 중 작은 미끄러짐은 따로 해석한다.
- 성공률뿐 아니라 시간, 결정 수, 전진/회전/정지 명령 수, lateral 명령 수, 실제 yaw 변화, 영상 검토 범위를 기록한다. 모델 호출은 0으로, LLM 협력이나 실물 성능으로 보고하지 않는다.
- 전체 회귀 검사와 GitHub CI를 확인한다. raw RGB 전체는 로컬에 보관하고 대표 영상·결정/평가 로그·메타데이터를 Git으로 공유한다.
