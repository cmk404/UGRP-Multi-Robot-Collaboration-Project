# 01 연구 질문과 동기

**기준 커밋: `origin/main` `1cd9ea1` (2026-09-26 확인).**

## 1.1 연구 질문

> 로봇들 사이의 자연어(한국어) 대화가 다중 로봇 작업 효율에 영향을 주는가?

이 질문은 저장소의 최상위 연구 질문이다. `docs/current_status.md` 첫 문단은
"통신 효과가 주 질문이며 ACT·Jev·맵 확대는 관련 보조 과제로 구분한다"고 적는다.
2026-09-25 결정 로그의 "연구 목표 강조" 항목도 같다: "핵심 질문은 자연어 대화가 효율에
영향을 주는가이므로, 로봇이 실제로 한국어로 대화해야 한다"
([docs/decision_log.md](../decision_log.md) 2026-09-25 절).

부 질문은 이전부터 같은 형태로 남아 있다. `docs/coela_communication_study.md`는
주 질문을 "완료율·완료 시간·실패 복구에 어떤 영향을 주며, 그 이득이 통신 비용을 상쇄하는가",
부 질문을 "정형 정보 공유에 비해 자유로운 자연어가 추가 이득을 주는가"로 적고,
"유한한 실험으로 모든 AI 협업에서 통신이 반드시 필요하다는 보편적 결론을 내리지 않는다.
무통신이 동등하거나 더 좋은 결과도 연구 결과로 보존한다"고 명시한다.

## 1.2 왜 지금 이 질문인가 — ZC2가 답하지 못한 것

2026-09-25 구역 통신 비교(ZC2)에서 동적 통신(`dynamic`)이 무통신(`independent`)보다
성공률이 높았다([05](05-results.md) 표의 ZC2 행). 그러나 이 결과를 "자연어 대화의 효과"로
읽을 수 없는 이유가 두 가지 기록돼 있다.

1. **대화가 한국어가 아니었다.** ZC2 18개 로그의 실제 전송 메시지는 129건(dynamic 75,
   plan_first 54)이고 "한글 포함 메시지는 0건"이다
   ([docs/design/2026-09-25-zone-korean-dialogue-codex.md](../design/2026-09-25-zone-korean-dialogue-codex.md)).
2. **dynamic의 이득이 메시지만의 효과가 아니다.** 정보·통신 경계 감사(R1)는
   "dynamic의 이득은 게시판·호스트 중재·메시지 묶음이라 메시지만의 효과로 볼 수 없다"고
   결론했다([experiments/2026-09-25-zone-comm-boundary-audit](../../experiments/2026-09-25-zone-comm-boundary-audit/README.md),
   교란 항목 C1). 같은 감사는 누설 L1(교사가 동료 의도로 로봇을 멈춤, 심각도 높음)과
   L4(영수증이 정답에서 나옴)를 찾았고, ZC2는 수정 전 실행이라 재검증하지 않았다.

즉 현재까지의 통신 비교는 "공통 자동 주행·조정 묶음 위에 대화가 더한 효과"까지만 말할 수 있다.
연구 질문을 제대로 묻기 위해 조건 축을 통신 채널만으로 좁혔다([02](02-experiment-design.md)).

## 1.3 TOP 카메라를 뺀 이유

사용자 결정의 근거는 결정 로그에 그대로 있다.

> "위에서 내려다보는 카메라가 있으면 로봇은 말하지 않아도 모든 상황을 알 수 있다.
> 그러면 대화 효과는 0에 가깝게 나올 가능성이 크다."
> ([docs/decision_log.md](../decision_log.md) 2026-09-25 "주 연구 조건 변경" 절)

공용 top RGB는 로봇 LLM 입력에서 빠지고 평가·채점용으로만 남는다. 대신 모든 호출에
정적 지도와 작업 지시서를 준다. 사용자 원문은 "정적 지도도 계속 llm이 볼 수 있게 … 실제
지도를 보면서 일하듯이 대신 실시간 상황은 못 보고"다(같은 절).

## 1.4 비유: 각자 운전하는 차들이 서로 말하면 이득이 있는가

이 연구의 구도는 "각 로봇이 자기 센서로 스스로 주행하고, 그 위에 통신을 얹었을 때
효율이 달라지는가"다. 자동차 V2X·협력 인지(cooperative perception) 분야의 질문 구조와
같다는 비유는 **2026-09-25/26 사용자 지시에서 제시된 것이며, 저장소 문서에는 아직
기록돼 있지 않다.** 저장소 전체 검색에서 `V2X`·`cooperative perception`·`협력 인지`
언급은 없다. 선행연구로 인용할 V2X·협력 인지 문헌은 **[출처 확인 필요]**다.

비유가 성립하는 지점과 성립하지 않는 지점은 현재 설계에서 구분된다.

| 항목 | 이 연구 | V2X 비유에서의 차이 |
|---|---|---|
| 각자 자기 센서로 행동 | 자기 손목 어안 RGB + 정적 지도 + 자기 명령 이력만([02](02-experiment-design.md)) | 유사 |
| 공유하는 것 | 자연어/정형 **메시지**. 원시 센서·좌표·정답은 공유 금지 | 협력 인지는 보통 센서·인지 결과를 공유 |
| 통신 비용 | 발화·추론이 SIM 시간을 소모(결정론적 비용 모델, PR [#186](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/pull/186)) | 대역폭·지연 비용에 대응 |

## 1.5 저장소가 인용한 선행연구

아래는 **저장소 문서가 실제로 인용한 것만** 옮겼다. 논문 내용에 대한 추가 주장은 하지 않는다.

| 인용 | 저장소 인용 위치 | 저장소가 적은 인용 이유 |
|---|---|---|
| Chen et al., ICRA 2024 (arXiv 2309.15943) | [docs/decision_log.md](../decision_log.md) 2026-09-25 절 | TOP 제거 결정의 "참고한 선행연구" |
| Guo et al., 2024 (arXiv 2403.12482) | 같은 절(두 곳) | TOP 제거 결정의 참고 문헌이며, 지휘자 겸임 결정의 근거 셋 중 하나로 "Guo et al. 2024의 지정 지휘자 설정과 맞는다"고 적음 |
| CoELA (arXiv 2307.02485) | [docs/coela_communication_study.md](../coela_communication_study.md), [docs/reference_alignment.md](../reference_alignment.md) | "특히 4장 모듈 구성과 5.4절 통신 제거 실험"을 참고. 공식 코드는 `UMass-Embodied-AGI/CoELA`. 저장소는 "CoELA 전체 재현을 주장하지 않고 모듈 분리 방식을 적용한다"고 명시하고, `docs/reference_alignment.md`의 차이표는 "전체 CoELA 재현표가 아니라 현재 구현을 설명하는 차이표"라고 적음 |
| CoLF (2026, arXiv 2602.07776) | [docs/design/2026-09-25-own-camera-oss-survey-claude.md](../design/2026-09-25-own-camera-oss-survey-claude.md) | "사족로봇 2대, 자기 영상 + 언어 기반 리더–팔로워, 통신 없음". 설계 참고용, 코드 공개 여부 미확인 |
| 분산 강화학습 운반(arXiv 2007.09243), 암묵적 통신 운반(PMC7806111) | 같은 조사 | 협동 운반 참고용 |
| **RoCo** | 저장소 문서에 인용 없음 | **[출처 확인 필요]** — `docs/`·`experiments/` 검색에서 RoCo 인용을 찾지 못했다. 최종 보고서에 넣으려면 서지사항과 인용 이유를 새로 확인해야 한다 |

### 중앙집중 대 분산 LLM 구도

저장소가 이 축을 다루는 근거는 결정 로그다. 조건 변경 결정은
"`leader`와 `dynamic`의 비교는 같은 대화라도 중앙 지휘 구조와 분산 구조의 차이를 본다"고
적는다. 지휘자를 별도 AI가 아니라 로봇 한 대가 겸하게 한 이유 셋도 같은 절에 있다.
첫째 LLM 수와 각 LLM의 입력이 다른 조건과 같아 통신 채널만 달라진다, 둘째 지휘하는 시간만큼
지휘자 자신의 작업이 늦어져 현실적 병목이 생긴다, 셋째 Guo et al. 2024의 지정 지휘자 설정과
맞는다([docs/decision_log.md](../decision_log.md) 2026-09-25 절).

Codex 통합 설계는 여기서 한 걸음 더 나아가, 중앙화 효과를 단독으로 주장할 수 없는 비교를
표로 정리했다. `③a−②`는 "star 지휘·권한 집중·지휘 부담의 결합 효과"를 뒷받침하지만
"중앙화 하나의 순수 효과"는 뒷받침하지 못한다
([2026-09-25-zone-dialogue-study-design-codex.md](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/pull/180) 7절,
현재 `origin/claude/records-0926` 브랜치 · PR [#180](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/pull/180)).
