# 2026-09-26 마커 없는 위치 추정 오프라인 탐침 (Kiro)

**질문(사용자, 2026-09-26).** 문기둥과 구역 입구에도 AprilTag가 꼭 필요한가? 태그 없이 정적 지도의 벽만으로 로봇이 자기 위치를 알 수 있는가?

**답(이 탐침의 범위 안에서).** 지금 경기장(0.10 m 회색 벽, 무늬 없는 벽면)에서는 태그 없이 벽의 바닥 경계만으로 문을 지날 만큼 정확하지 않다. test 6회 전체 p50 7.7 / p90 51.4 cm, 문 근처 p50 32.9 / p90 82.9 cm였다. 같은 프레임의 태그 PF는 전체 2.0 / 7.0 cm, 문 근처 1.8 / 3.6 cm였고, 명령 적분만 하면 전체 32.8 / 89.4 cm였다. 설계 권고는 [설계 문서](../../docs/design/2026-09-26-markerless-localization-and-memory.md)에 있다.

- 작성: Kiro(`kiro/markerless-research`). 실행 소스 `f74e3e7`(테스트 실행 전 커밋, `prereg.json`).
- 성격: 기록된 M1 프레임의 **개루프 오프라인 재생**이다. 궤적은 태그 PF가 몰았다. 폐루프 성공·문 통과를 주장하지 않는다.
- 새 시뮬레이션·모델 호출: 없음. 프레임에는 실제 태그가 찍혀 있지만 검출·해독하지 않았다.

| 고정 보정 | K·D, M1 운동 모델(`calibration_m1_dev.json`), 고도 편향(dev에서 GT로 오프라인 적합) |

| `eval_only/` | `calibrate`(dev만)와 `score`만 읽음. `localize`는 열지 않음(테스트로 확인) |

## 방법 요약

1. 어안 프레임을 측정 K·D로 핀홀로 되돌린다.
2. 48개 열마다 아래에서 위로 바닥 후보 행 `vb`를 본다. 발행 PWM FK와 자세별 고도 편향으로 바닥 거리를 구하고, 0.10 m 벽 윗모서리 행 `vt`를 계산한다.
3. 띠가 균일하고 아래·위와 다르면 벽 띠로 받는다. 겹치지 않게 열마다 3개까지 둔다.
4. 파티클마다 지도 윤곽을 바닥 궤적·벽 높이 궤적으로 광선 추적한다. 예상 아래·윗모서리와 비교한다(max-mixture, 이상치 하한, 유효 열 8).
5. 짐을 든 동안 청록 짐 영역을 가린다. 아래모서리가 가려지면 윗모서리와 비교한다.
6. 필터 본체는 M1 PF(`22c84842:harness/owncam_localizer.py`, sha256 `0304d7c4…`)를 상속했다. 측정만 바꿨다.

### 사후 진단 (test 뒤에 작성, 사전 등록 아님: `posthoc_door_carry.py`, `results/posthoc_door_carry.json`)

- 오차가 15 cm 이상인 문 근처·운반 프레임(6프레임마다)에서 GT 자세와 틀린 추정 자세의 스캔 우도를 비교했다.
- GT가 더 높은 우도를 받은 비율은 문 근처 31%, 운반 26%였다. 나머지에서는 **측정 자체가 틀린 자세를 더 좋아했다.** 필터 조정만으로는 고쳐지지 않는 모호성이다.
- 관측 열 중 σ 3배 안으로 맞은 비율도 GT 28% 대 추정 35%(문 근처)로, 틀린 자세가 오히려 더 많은 열을 설명했다.
- 문 근처 오차는 주로 칸막이 벽을 따라(y) 났다. 중앙값은 s102 +0.59 m, s105 +0.39 m, s104 +0.26 m였다. s101은 x 방향(−0.20 m)이었다. 긴 칸막이 벽 하나만 보이면 벽 방향 위치가 관측되지 않는다(조리개 문제). 문 틈과 문기둥이 그 방향을 고정해야 한다.
- dev 영상에서는 0.10 m 벽 너머의 바닥·도색·반대편 벽이 문 틈에 가짜 띠를 만들었다. test 프레임에서 같은 원인인지는 영상으로 확인하지 않았다.

## 검토 범위와 한계

- 태그가 찍힌 영상이라 벽 띠의 일부 열은 태그 판 때문에 버려졌다. 태그가 없는 벽에서는 검출 열이 늘 수 있다. 반대로 태그 판 가장자리가 띠 검사를 통과한 열도 드물게 있을 수 있다.
- 조명·벽색·체커 바닥에 맞춘 문턱이다. 다른 지도 버전에는 다시 맞춰야 한다.
- 전역 초기화(균등 분포)는 구현만 했고 test에서 돌리지 않았다.
