# 영상 기반 파지: 구조 보완과 실제 검증

## 판정

영상 관측 → 자체 명령 이력 → 국소 동작 학습 → 정렬/닫기/확인/복구 경로를 새 실험 실행기에 구현했다. **안정적인 정렬과 물리 파지는 해결되지 않았다. 최신 후보를 성공 후보로 채택하지 않는다.** 기존 stateless baseline은 보존되어 있다. 실험 당시 소스를 먼저 커밋하고 실행 중 고정했다. 서로 다른 코드와 모델 출력으로 진행한 진단이므로 성공률 비교나 tracker 단독 효과의 통제 실험으로 해석할 수 없다.

## 구현 및 검증 범위

- RGB 차이와 자기 명령으로 overhead의 자기 로봇 식별을 검증한다. 초기 잘못된 자기 식별을 실제 실행에서 거부했다.
- 현재/이전 자기 카메라·동일 overhead 영상, 자기 발행 명령을 관측기에 제공한다. 추가 crop은 같은 overhead JPEG의 픽셀에서만 생성된다. 시뮬레이터 위치·관절 측정·접촉·평가값은 제어 입력에 들어가지 않는다.
- 기존 SEARCH_POSE 명령을 명시적으로 발행하고 기록한 뒤 작은 변화량만 허용한다. 첫 동작의 잘못된 중립 PWM 도약과 반복 drive 차단을 수정했다.
- 8회 양방향 보정 동작과 같은 view/근처 영상 상태의 국소 오차 모델을 구현했다. r1-v4에서 25개 전이와 11개 모델 동작이 실제 실행됐다. 비교 가능한 다음 영상 9개 중 오차 감소 3개, 증가 6개였다.
- LK 전후방 검증·텍스처·광도 검사, 최대 3프레임 제한 추적, 오차 증가 후 되돌리기, 정렬 정체 후 바퀴 재배치를 추가했다. 되돌리기는 자동 테스트에서 검증됐지만 r1-v5에서는 모델 동작 자체가 없어 실제 발동 검증은 못 했다.
- 2회 연속 영상 정렬 이후 닫기, 시각적 포획/상승 확인, 재열기/재시도/중지 경로를 구현하고 테스트했다. 실제 닫기 조건에는 도달하지 못했다. 두 로봇 교대 실행 인터페이스는 있지만 최신 후보의 공동 파지는 실행하지 않았다.
- 카메라 위치·장면·물리 파지 구조를 바꾸지 않았으며 weld는 꺼져 있다. 모션은 모터/서보 명령으로 발생한다.

## 영상 검토와 남은 갭

원본 overhead 0/8/16/24/36/47회 프레임과 후처리 표시를 확인했다(`r1-v5-review.jpg`, 빨강=집게 추정점, 초록=목표 추정점). 로봇은 물체 근처로 이동했으나 집게가 물체를 감싸지 못했다. 집게가 영상에서 매우 작고, 표시된 점의 정확한 물리적 끝단 대응은 모든 프레임에서 확정할 수 없다. LK는 픽셀 움직임을 검증할 뿐 점이 집게라는 의미를 증명하지 않는다. `comparison.mp4`는 v4/v5 실제 모션을 나란히 보여준다. 이 표시는 모델 입력이 아니다.

남은 핵심은 (1) 작은 집게 끝단/목표의 정확하고 지속적인 대응, (2) 현재 영상 상태에서 오차를 줄이는 동작 예측의 신뢰성, (3) 2D 중점 정렬만으로 부족한 집게 방향·높이·물체 폭 조건이다. 접촉 판정 없이 영상으로 닫기/들기를 확인하는 단계와 공동 파지는 실제로 검증되지 않았다. 다음 검증은 동일한 고정 영상/명령 전이에서 수동 검토한 끝단 대응과 예측 방향을 비교하고, 오차 감소가 재현된 뒤 단일 로봇 닫기와 두 로봇 단계로 확장해야 한다. 실패를 숨기기 위해 임계값을 완화하거나 평가 좌표를 제어에 넣지 않는다.

## 재현 및 보관

- 각 하위 폴더에 result, summary(존재하는 경우), 평가 로그, 당시 input-audit, 대표 현재/이전 원본 JPEG와 wire 요청을 저장했다. `summarize.py --include-evaluation <raw-root>...`로 통계를 재생성할 수 있다.
- 전체 원본은 `/Users/changmin/projects/ugrp/outputs/visual-servo-20260909-<실행>/`에 로컬 보관된다. `raw-manifest.json`은 파일 경로·크기·SHA-256을 보존한다. 모든 wire와 원본 영상 전체를 원격 백업한 것은 아니다. 대표 자료만으로 전체 감사 재실행은 불가능하며 전체 로컬 원본과 해당 source SHA가 필요하다.
- `environment.json`은 최종 실행 종료 직후 변경되지 않은 Python 환경을 기록했다. 모델은 gemini-3.8-flash이며 모델 호출 동안 물리는 일시 정지한다. 실물 실시간 제어 검증은 아니다.
- 로컬 필수 검사: 282 tests / 140 subtests 통과. PR CI 결과는 PR에서 확인한다. 이 작업에서 시작한 실험 세션은 모두 종료했다.
- GitHub PR: https://github.com/kcm0127-dotcom/ugrp/pull/24 . main 병합은 사용자 검토·명시 승인 전까지 진행하지 않는다. UGRP 지침에 따라 Drive를 사용하지 않았다.
