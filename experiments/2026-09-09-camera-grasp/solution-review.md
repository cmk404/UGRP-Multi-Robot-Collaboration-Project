# 실제 카메라 배치를 유지하는 파지 해결방안

2026-09-09 수정. 사용자 조건: 실제와 다르게 집게가 보이도록 카메라를 옮기지 않는다. 이전 카메라 프레이밍 변경 제안은 철회한다. 카메라 장착 위치·화각·물리·외관을 유지하고, 해당 로봇의 자기 영상과 공용 상단 영상만을 외부 관측으로 사용한다. 이번 작업은 조사와 기록 수정이며 제어 코드 변경과 추가 실험은 없다.

## 확인한 실패

기준 SHA `15db9f58f65eb3ba7289e7ec7c90402a851d7833`, seed 11, 로봇당 30판단. 60회 중 48회 집게 열기, 닫기와 서보 3/4/5 조절은 0회. 실제 요청 60건의 이미지 전용 입력 감사 통과. README.md와 result.json 등에 결과 보존. 집은 뒤 미끄러짐보다 집기 동작으로 진입하지 못한 실패다.

`harness/camera_pair_policy.py`는 매 요청을 새로 구성하며 memory/history를 명시적으로 금지한다. raw 절대 PWM은 선택할 수 있지만 직전 명령을 모른다. 반복 구간에 이미지 해시가 동일한 사례가 있고, 응답에서 자기 로봇의 상단/하단 식별도 흔들린다. 각각의 영향은 분리 시험 전이므로 확정 원인으로 주장하지 않는다.

## 우선안: 영상과 자기 행동의 이력

현재 영상 + 최근에 자신이 발행한 명령 + 이전 영상으로 다음 동작을 정한다. 외부 관측의 출처는 기존 두 카메라 그대로다. 과거 이미지와 자기 명령은 새로운 센서의 정답 정보가 아니지만 기존 stateless 시험과 다른 조건이므로 입력 명세와 감사기를 함께 바꿔 구분해야 한다.

- 먼저 최근 자기 명령 4개만 추가한 조건을 기준 정책과 비교한다. 발행한 명령은 실행 성공이나 측정된 관절 상태가 아니다. 기록에 '열림 완료', '파지 성공' 같은 확인하지 않은 사실을 붙이지 않는다.
- 다음 별도 조건에서 직전 자기/상단 영상 한 쌍을 추가한다. '열기를 요청했으나 영상에서 변화가 확인되지 않음'과 '열기를 아직 요청하지 않음'을 구별한다. 보이지 않는 상태는 미확인으로 유지한다.
- 반복 명령을 강제로 닫기로 바꾸는 매크로는 사용하지 않는다. 모델이 실제 팔 조절과 닫기를 선택하는지 평가한다.
- 자기 식별이 계속 흔들리면 기존 구동 범위 내 작은 동작의 전후 영상으로 상단 영상의 어느 로봇이 반응했는지 연관 짓는 방법을 검토한다. 장착 카메라 재배치나 표식 추가는 없다. 두 로봇이 동시에 움직이면 연관이 모호해질 수 있어 별도 진단이 필요하다.

## 이력만으로 부족하면: 행동과 영상 변화의 관계 학습

기억을 추가해도 범용 VLM이 MasterPi 팔 제어를 배웠다는 뜻은 아니다. 고정된 실제 카메라 구성에서 짧은 서보 명령과 전후 영상 사례를 수집하여 동작이 물체의 영상상 위치·크기·상단의 팔 형태를 어떻게 바꾸는지 학습한다. 관측 불가능한 집게 끝을 직접 추적한다는 가정을 두지 않는다.

초기에는 소수의 영상-명령 사례를 정책에 제공하는 진단으로 시작할 수 있다. 정밀도가 부족하면 동일한 입력 조건의 시연 데이터로 작은 로봇 전용 제어 정책을 학습하고 상위 모델은 목표/단계를 담당하도록 한다. 시연은 허용된 영상과 raw 명령으로 만들고, 과거 정답 좌표 기반 성공 경로를 학습 데이터나 고정 파지 매크로로 몰래 넣지 않는다. 성공 시연을 아직 확보하지 못했으므로 즉시 학습 가능한 상태는 아니다.

후보 동작을 예측하고 짧게 실행한 뒤 영상을 다시 보는 접근은 데이터와 보정이 필요하다. 물체가 팔 동작을 따라 움직이는지 등은 시각적 증거가 될 수 있으나 접촉·견고한 파지의 증명은 아니다. 두 카메라와 이력으로도 구별되지 않는 숨은 상태는 불확실성으로 남긴다.

## 바로 실행할 비교와 판정

1. 기준 정책 vs 최근 자기 명령 4개 추가. 카메라·모델·물리·seed 11·각 30회 예산 고정. 변경 소스를 먼저 커밋하고 실행 SHA 연결.
2. 다음 비교에서만 직전 영상 한 쌍 추가. 조건을 한꺼번에 바꾸지 않는다.
3. 초기 비교에서 유망하면 여러 seed로 반복한다. 반복 감소만으로 파지 성공을 선언하지 않는다.

동일 명령 연속 길이, 최초 서보 3/4/5 및 닫기 선택, 성공률, SIM 시간, 행동 수, 토큰을 함께 기록한다. 기존 성공 기준인 양 로봇 bilateral + 3cm 상승 + weld OFF 2초 유지는 출력 평가에만 사용한다. 모델이나 제어 단계 전환에 정답 좌표·접촉·관절 상태·평가 결과를 전달하지 않는다. 모든 실제 요청을 보존·감사한다.

## 연구 자료와 적용 한계

- [Online Replanning in Belief Space (저자 논문)](https://arxiv.org/abs/1911.04577): 부분 관측에서 새 관측으로 추정을 갱신하고 다시 계획한다. 이력과 불확실성을 다루는 방향의 근거이며 현재 MasterPi나 카메라 두 장만의 파지 성공 근거는 아니다.
- [Visual Foresight (BAIR 연구팀 설명)](https://bairblog.github.io/2018/11/30/visual-rl/): 행동에 따른 영상 예측을 학습하고 첫 동작 실행 후 재관측·재계획한다. 해당 연구는 팔 위치 정보도 사용했으므로 우리 영상+명령 전용 조건을 그대로 입증하지 않는다.
- [Diffusion Policy 공식 프로젝트](https://diffusion-policy.cs.columbia.edu/): 시각 조건과 행동 시퀀스, 짧게 실행하고 다시 계획하는 제어를 학습한다. 특정 Push-T 실험의 가림 강건성을 집게가 계속 안 보이는 공동 파지의 증거로 확대하지 않는다. 우리 로봇의 데이터/행동 형식에 맞춘 학습이 필요하다.
