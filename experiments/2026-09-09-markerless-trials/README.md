# 표식 없는 상자 시행착오 기록

[상세 보고서](../../docs/markerless_improvement_trials_20260909.md)의 로컬 실행 결과표를 Git에서도 조회할 수 있도록 보존했다. N1 1회 및 N3~N7 각 5회, 총 26회다. N1 1/1, N3 4/5, N4 3/5, N5 3/5, N6 4/5, N7 5/5이며 후보 간 성공을 합산하지 않는다.

- [실패를 포함한 26회 결과](trial-outcomes.json): 호출·입력 토큰·SIM 시간·종료 사유·로컬 위치.
- [대조 범위와 원본 해시](audit.json): 26개 로컬 result.json의 성공 여부·종료 사유·SIM 시간을 결과표와 대조했다. 호출·토큰은 기존 기록을 복사했으며 이번 감사에서 재집계하지 않았다.
- [N7 실행 코드 연결](../2026-09-09-markerless-n7/code-version.json): 사후 커밋과 고정 소스 125개 파일의 해시를 다시 대조했다. 이전 후보에 N7 커밋을 소급 적용하지 않는다.

M4 기준 2/5는 [별도 보고서](../../docs/markerless_blocks_20260909.md)에 있다. N2는 전체 실험 전 영상 QA에서 폐기했으며 진단 재생·중단은 이 결과표의 분모에 포함하지 않는다. 원본 영상·로그와 이전 후보의 소스 스냅샷은 로컬에만 있다. 이 폴더는 전체 과거 실험을 이관한 기록이나 원격 원본 백업이 아니다.
