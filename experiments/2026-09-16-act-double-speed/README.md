# 2배 명령 교사 ACT와 일반화 시험 — 사전 계획

전진 명령을 기존 교사의2배로 하되 기존0.15상한,0.2초 실행 주기,4mm 준비 판정을 유지한다. 녹화 배속이나 기존 표적만의 배수 변경이 아니라 실제 물리 실행에서 시연을 새로 수집한다.
기존과 같은55개 시작 거리(학습50/개발5)를 사용한다. 성공한 교사 시연만 학습하되 모든 실패/제외는 기록한다. 실제 관측 주기와 새 궤적을 그대로 사용한다.
공식 ACT, frozen ImageNet128, 1만 업데이트/로봇, 두 초기값, 개발 체크포인트 선택을 유지한다. 느린 접근 샘플링 경계만0.015→0.03으로 교사 명령과 함께2배로 한다.
최종 시험32개(새 범위 내8, 시작 거리 변화8, 횡방향 변화8, 회전 변화8)를 이 파일과 protocol.json에서 학습 전에 고정한다. 교사2배/기존ACT/새ACT두초기값을 같은 조건에서 비교한다. 가까운 시작은 시연 중간 상태와 겹칠 수 있으므로 강한 외삽으로 해석하지 않는다.
교사 실패·학생 성공은 같은 공통 실행기·동일 조건에서만 세며, 단일조건의 우월성을 일반 능력으로 확장하지 않는다. 모든 시험 결과를 보고하고 시험 후 수정/재학습하지 않는다.
팔·집게는 공통 기존 스킬이며 전진·정지만 학습한다. 횡방향/회전 시험은 미학습 오차에 대한 허용 범위 시험이지 해당 방향의 보정 행동 학습이 아니다. 학생 입력은 두RGB뿐이며 교사 정답은 분리한다. 카메라/FOV/외관 유지, weld OFF.
코드와 사전계획은 실행 전 커밋한다. raw RGB/체크포인트/영상은 로컬에 저장하며 원격 백업이라고 부르지 않는다.
