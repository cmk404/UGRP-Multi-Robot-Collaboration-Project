# 출발 거리·각도·좌우 위치를 바꾼 전체 E2E 검증

사용자 요청: 다양한 거리와 각도에서도 전체 운반이 되는지 확인한다.
19개 배치를 실행 전에 cases.json에 고정하고 각 배치에서 local/llm 두 조건을
한 번씩 실행한다(총 38회). 기준 1, 거리 4, 각도 4, 좌우 위치 4, 혼합 6개다.
거리 30–70 cm는 기존 시연 파지 위치로부터의 초기 x 후퇴량이다.
좌우 위치 ±6 cm는 world y 초기 편차, yaw ±10°는 초기 방향이다.
카메라 방향/FOV를 바꾸는 실험이 아니며 로봇 부착 카메라는 로봇과 함께 회전한다.

제어 알고리즘과 모델은 11da613 후보 그대로 유지한다. 이번 소스 변경은
장면 초기화의 yaw/lateral 설정 및 실행/기록만 추가한다. 출발 배치 수치는
장면 설정과 평가 기록에만 저장하며 모델/로컬 제어기에 전달하지 않는다.
기존 근거리 실행기의 기본 최대 거리 45 cm는 유지하고 E2E 장면만 70 cm까지 허용한다.
별도 재학습·임계값 조정·실시간 정답 보정 없이 고정한 후보의 성능을 측정한다.

성공 기준은 기존과 동일: 실제 접근 → 양쪽 파지/들기 → 50±3 cm 운반 →
목표 구역 내려놓기/해제/안정, 기존 물리 평가 전 항목, 접근 화물 충돌 0,
weld 0, 카메라/형상/마찰/질량 불변, 오류 없음. 원본 RGB/명령/LLM wire를 재생 감사한다.
LLM은 기존 두 독립 요청의 단계 허가 방식이며 자유로운 행동 계획이 아니다.
추론 중 SIM 정지, 고정 평지/물체/역할 조건도 유지한다.

각 배치의 local과 llm을 연속 실행한다. 실패해도 다음 배치를 계속 실행하고
실패 단계, 시간, 명령 수, LLM 토큰/호출 수, 물리 결과를 모두 남긴다.
입력 감사 실패나 프로세스 비정상 종료는 운반 실패와 구분한다.
동일 소스/모델 파일 해시를 매 실행 전 확인한다. 중간 결과를 보고 배치를
선별하거나 제어기를 수정하지 않는다. 진단 결과와 향후 수정 제안을 별도로 기록한다.

각 영상에서 균등 추출 프레임과 실패 직전의 허용 카메라 입력을 검토한다.
19개 선택 배치의 엔지니어링 검사이며 전체 공간의 성공률, 반복 통계,
LLM 통신의 효과 또는 다양한 지형의 성공으로 해석하지 않는다.
raw 영상/로그는 로컬 outputs에 보관하며 Git에는 소스/설정/전체 결과와
해시, 선택 영상·검토 시트를 저장한다. Google Drive는 사용하지 않는다.
