# 기존 스킬 통합 검증

이전 raw-action 진단 D1/D2/D3는 기존 성공 스킬을 호출하지 않았다. 본 작업은 실제 모델/실행기 연결을 수정하며, 합의된 담당 로봇을 모델 슬롯과 물리 포트에 연결한다. 학습 범위 이탈을 raw LLM 명령으로 대체하지 않는다.

- B0: 수정 전 SHA d1c36124e1a925ea02a857d9e55cc7be68b59de8에서 기존 3대 실행기, fixture 합의 + local 제어 재현. 기존 성공 설정/모델. 실제 물리 성공 확인. 결과 `outputs/dispatch-skill-baseline`.
- S1 이후: 새 실행 SHA를 커밋한 뒤 동일 SHA 고정. 기존 open arena에서 실제 3개 LLM 합의 → 스킬 바인딩 → 기존 접근/파지 모델 및 VisualBoxSkill/VisualMacroExecutor → 지도 경로. 모든 실패를 기록.
- shared_crossing의 0.685m 통로는 기존 평행 대형의 보수적 0.93m 정적 한계보다 좁다. 회전 스킬은 연결돼 있지 않으므로 해당 경로는 운반 전에 거부. open은 기존에 만든 별도 조건이며 shared_crossing 성공으로 해석하지 않는다.
- 기존 카메라·물체·로봇·지도 기하 유지, weld OFF. 관측은 own RGB / TOP RGB / 정적 지도 / 자기 발행 명령. TOP 이미지의 빔 중심을 기준 이미지에 평행 이동하는 전처리만 추가. 원본/변환/자기 영상 해시를 보존하고 모델 가중치 및 학습 지지영역 기준 유지. 새 배경을 참고 이미지로 덮어쓰지 않는다.
- 실제 평가 정보는 referee-only.jsonl 및 evaluation-only.json. 단계 전이나 모델 예측에 평가 정보를 사용하지 않는다. 기존 시연 팔 동작 재생과 학습 모델/RGB 바퀴 제어를 구분한다.
- 새 경로 측방 이동과 모델의 새 환경 적합도는 실험 대상이며, 모델 연결이나 단위 검사만으로 성공을 선언하지 않는다.
- 출력/실패/영상은 outputs/ 원본 유지. 결과/SHA/설정/모델 해시/검토 범위/비용 집계를 experiments/에 기록한다. 원본은 로컬 보관이다.
