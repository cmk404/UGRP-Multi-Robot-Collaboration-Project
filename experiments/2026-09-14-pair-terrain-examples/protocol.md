# 예시 지형 구성·정적 렌더 검증

사용자 요청: 앞서 제안한 각 예시 지형을 우선 구성한다.
이번 범위는 평지 5종의 대표 배치와 완전 차단 대조 1개이다. 15조건 코호트 실행,
경사/단차, 파지·운반·내려놓기 실험은 이번 구성 작업에 포함하지 않는다.

기반은 PR #44 head 85fb0461efa5598656032139d8cb907c975cd1ab이다.
기존 actor 카메라/FOV/로봇/빔/물성/바닥을 유지하고 authored 벽만 추가한다.
모든 배치의 경계는 기존 2.93 × 1.75 m, 벽 높이는 0.30 m이다.
원래 창고 물체는 제거하지 않는다. 표시 경로는 평면 기하 계획이며 실제 통과 성공이 아니다.
정적 렌더는 기존 folded setup 0.9초만 수행하고 파지·주행은 실행하지 않는다.
렌더의 수치 설정은 기존 기본값 impratio=1, weld OFF, NoSlip 반복 0이다.

소스·지도·본 프로토콜을 커밋한 뒤 별도 새 출력 디렉터리에서 렌더한다.
지도 검증: 기존 스키마, 전체 하중 footprint, 직선과 회전 중 공간,
명목 시작과 주변 9개 시작 좌표에서 경로 존재 여부를 검사한다.
주변 좌표는 설계 견고성의 기하 비교이며 실제 시작 좌표로 actor에 제공하지 않는다.

렌더 검증: 지도 벽의 위치/크기/높이와 컴파일된 MuJoCo geom의 일치,
원래 geom·카메라 유지, 초기 로봇/빔과 새 벽의 겹침 없음, weld OFF를 확인한다.
원본 top/own/observer RGB, 컴파일 XML, 해시, 환경, 소스 SHA, 검토 범위를 보관한다.
그 뒤 도면과 실제 top/observer 이미지를 직접 확인한다.
세션 래퍼로 시작하고 종료 시 이 작업 소유 프로세스만 정리한다.

판정은 지형 구성 및 기하 경로 검증이다. 실행 제어 입력/성공률/물리 통과로 해석하지 않는다.
S자 경로는 현재 메카넘 모델에서 측방 이동을 이용할 수 있어 차체 yaw 회전은 강제하지 않는다.
개발 중 첫 복수 장애물 배치는 회전 공간을 차단하여 두 기둥의 배치 간격을 조정했다.
S자 배치는 도착 쪽 여유가 6 cm 격자보다 작아 명목 시작의 작은 변화에 경로가 끊겼다.
도착 쪽 벽만 4 cm 옮겨 같은 굴곡을 유지하면서 주변 9개 기하 시작에서도 경로가 나오게 했다.
시작 쪽 벽도 함께 옮긴 중간 후보는 ±15° 초기 6.5 cm 확인 동작 공간을 침범했다.
최종 배치는 시작 쪽 벽을 원위치로 돌리고 모든 지형에서 이 확인 동작 공간도 검사한다.
경계에 붙인 벽은 부동소수점 경계 오차를 피하도록 1 mm 안쪽에 두며, 이 틈은 통로가 아니다.
