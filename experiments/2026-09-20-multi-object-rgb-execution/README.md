## RGB 추적과 계약 검사

[자세 변화 진단](pose-sweep-result.json): 코드 `42024aa`, 16프레임·48물건 관측에서 ID 오류 0개.

로봇이 물건을 운반한 실험이나 물리적으로 실현한 궤적이 아니다. 가림·교차의 실제 운반 일반화는 미검증이다.

## 검토 범위와 미완료

v1 planning TOP, v2 접근 중 TOP, v3 종료 TOP, 자세 변화 진단 마지막 TOP을 원본 해상도로 확인했다.
모든 동영상 프레임이나 개별 자기 시점 전 프레임을 검토한 것은 아니다. 물건은 최종 장면에서도 시작 위치에 남았다.
판정의 근거는 기록된 모델 응답/발행 명령/별도 최종 평가이며, 영상 몇 장으로 전체 과정 안전을 주장하지 않는다.

남은 핵심 작업은 RGB 목표 ID를 기존 접근·파지 실행기에 연결하고 단일 상자부터 실제 완료를 얻는 것이다.
이번 raw-action 모델 경로는 낮은 신뢰도에 따른 대기와 짧은 동작마다의 호출 비용 때문에 예산 내 접근도 끝내지 못했다.
학습 파지·ACT·일반 경로 입력 확장, 실제 반복 운반/임시 적치, 물건별 완료·전체 성공 검증은 아직 남아 있다.
