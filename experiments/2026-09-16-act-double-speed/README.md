# 2배 명령 교사로 학습한 ACT: 속도 향상과 일반화의 한계

실제 빠른 교사의 시연을 새로 수집해 ACT를 두 번 학습하고, 학습 전에 고정한 32개 조건에서 교사·기존 ACT·새 ACT 두 모델을 비교했다. **학습 범위 안의 속도 향상은 두 학습에서 재현됐지만, 교사가 실패하는 조건을 안정적으로 해결하는 일반화는 입증되지 않았다.**

## 최종 물리 시험

| 조건 | 2배 교사 | 기존 느린 ACT | 빠른 ACT seed16 | 빠른 ACT seed17 |
|---|---:|---:|---:|---:|
| 새 범위 내 거리 8개 | 8/8 | 8/8 | 8/8 | 8/8 |
| 더 가까운 시작 4개 | 4/4 | 4/4 | 4/4 | 4/4 |
| 더 먼 시작 4개 | 0/4 | 4/4 | 3/4 | 0/4 |
| 횡방향 오차 8개 | 3/8 | 1/8 | 0/8 | 0/8 |
| 방향 오차 8개 | 0/8 | 0/8 | 0/8 | 0/8 |
| 전체 | 15/32 | 17/32 | 15/32 | 12/32 |

성공은 접근 준비 + 공통 파지·들기 성공 + 접근 중 물체 접촉 0 + 실행 오류 없음이다. 128회 모두 실행 오류·시간 초과 없이 종료했다. 동일한 32개 조건을 네 방법으로 비교했으므로 독립된 128개 장면으로 해석하지 않는다. 두 초기값도 같은 32개 장면을 사용했다. 새 범위 내 조건은 학습 초기 거리 0.20–0.30m 안에서 새로 뽑은 8개 조합이며, 더 먼 시작은 0.34–0.44m, 더 가까운 시작은 0.12–0.18m다. 가까운 시작은 학습 중간 상태와 겹칠 수 있어 강한 외삽 증거가 아니다. 횡방향은 ±1.5/3cm, 방향은 ±4/8도다.

## 실제 속도 차이

새 범위 내 8개에서 기존 ACT의 평균 접근 시간 11.60초가 빠른 ACT 두 모델 모두 4.10초로 줄었다. 접근은 **2.83배 빠르며 64.7% 단축**됐다. 평균 명령 수는 117→42다. 공통 팔·파지 동작까지 포함한 전체 SIM 시간은 27.26→19.76초로 **27.5% 단축, 1.38배**다. 학습한 부분은 전진·정지이므로 전체 작업이 2배 빨라졌다고 부르지 않는다. 영상 배속이 아니라 실제 시뮬레이션 물리 시간의 변화다. 명령 2배가 물리 완료 시간 정확히 2배를 뜻하지도 않는다.

## 교사를 넘었는가

2배 교사가 실패한 17개 조건 중 fast16은 3개(distance_shift-05/06/07), fast17은 0개를 성공했다. 기존 느린 ACT는 그중 먼 시작 4개와 횡방향 1개, 총5개를 성공했다. fast16의 성공만 고르면 우월해 보이지만, 반복 학습에서 재현되지 않았으며 전체 성공률도 개선되지 않았다.

더구나 먼 시작의 2배 교사는 정지 직전에는 4mm 기준에 들어와도 감속 후 관성 이동으로 범위를 벗어나 준비 판정을 취소했다. 예를 들어 distance_shift-05는 최종 오차가 약4.17/4.75mm였고 파지는 시도하지 않았다. fast16의 같은 조건 성공은 약1.18/6.77mm, 06은 약0.35/4.91mm 오차에서도 공통 파지기가 성공한 결과다. 따라서 이것을 더 정밀한 정지 제어의 증거로 해석할 수 없다.

사후 진단으로 모든 방법에 동일한 최종 x오차 ±4mm를 적용하면, 교사 실패 중 fast16의 성공은 07 하나(3.32/3.66mm)만 남고 fast17은 0개다. 이는 사전 성공 기준을 바꾸거나 실행 제어에 정답을 넣은 것이 아니라, 판정 기준 차이를 확인하는 별도 분석이다. 원래 1배 교사로 같은 실패17조건을 재실행한 사후 진단에서는 6/17 성공했다. 먼 시작 4/4, 횡방향 2/5, 방향 0/8이다. 특히 빠른 교사가 실패한 먼 시작4개는 모두 원래 속도로 성공했다. 따라서 빠른 학생의 일부 성공을 교사에게 원래 불가능했던 기술의 획득으로 볼 수 없다. 이 진단은 128회 주 비교에 합산하지 않았으며 학생을 수정하지 않았다. 동일 초기 물리 상태·첫 두RGB를 모두 확인했다.

현재 합리적인 판정은 **빠른 시연의 모방은 가능하고, 일부 거리 외삽 성공은 관측했지만 안정적인 일반화는 부족하다**이다. 횡방향·회전 보정 행동은 학습 행동 공간에도 시연에도 없으므로 이번 결과로 새 보정 기술의 출현을 기대할 근거는 없다. ACT 자체의 일반화 불가능을 증명하는 시험도 아니다.

## 데이터·모델·입력 경계

- 기존과 같은 55개 초기 거리에서 실제 2배 명령 교사로 다시 실행했다. 55/55 성공, 제외0, 접근 접촉0, 수집450.27초. 기존55개 평균 접근11.3909초→새 교사4.10초. 명령상한0.15, 제어주기0.2초, 준비판정4mm는 유지했다. 새 데이터 최대 명령0.12라 상한에 걸리지 않았다.
- 학습50/개발5를 사전 분리했다. 새 시연은 로봇별 학습1050프레임+정지 기준 이미지1개, 개발105프레임이다. 최종32조건을 학습 전에 고정했고 시험 후 모델을 수정하거나 재학습하지 않았다.
- LeRobot 공식 ACT 코드 SHA `89236ea0f4f81a81ca566081e20dd1ff5f823cbe`, RGB-only device 패치2줄 유지. ImageNet ResNet18을 고정하고128px RGB를 사용했다. 로봇별 총11,418,898개 중251,986개 파라미터를 학습했다. 원 논문의 전체 설정을 그대로 재현한 것은 아니다.
- 두 seed20260916/20260917, 로봇별10,000업데이트, batch32, AdamW1e-4→cosine1e-5, chunk4 중 첫 행동 실행, 균형 샘플링. 느린 구간 샘플링 경계만 교사 속도와 함께0.015→0.03으로 변경했다. 개발 점수로 체크포인트 선택: seed16 r1/r3=9000/9500, seed17=8000/10000. 각 모델 개발 정지 누락·오검출 모두0. CPU2스레드 학습9.47/11.54분.
- 개발 물리 시험은 각3/3이며 최종 시험 성공률에 합치지 않았다. 개발 입력 적합도0오류는 실제 일반화 성공을 보장하지 않았다.
- 학생 ACT 실행 입력은 현재 자기RGB와 고정topRGB 두 장뿐이다. 기록한 자기 발행 명령 이력도 ACT에 입력하지 않았다. 정답 위치·관절·접촉·평가·교사 관측은 입력·행동 보정에 쓰지 않았다. 초기 상태 설정과 별도 사후 평가에만 사용했다. 교사는 승인된 학습·비교 경로에서 정답x좌표를 사용한다.
- 카메라/FOV/외관 유지, weld OFF. 팔·집게는 모든 방법에 같은 기존 RGB 스킬을 사용했다. 운반·다른 물체·조명·새 지형·실물 로봇 일반화는 시험하지 않았다. 생산 기본 kernel 정책은 바꾸지 않았다.

## 원인과 다음 실험의 우선순위

이번 데이터는 잘 정렬된 직선 접근만 담고 있다. 학습 데이터와 가까운 영상에서는 빠른 동작을 재현하지만, 먼 시작으로 달라진 영상/동작 궤적에서 정지 출력을 놓치는 문제가 나타났다. 이는 관측된 실패 양상이며, 표현학습·표본 부족·정책 민감도 각각의 인과 기여는 아직 분리하지 않았다.

다음 단계는 단순 학습 횟수 증가보다 (1) 거리·횡방향·방향·주행속도를 다양화한 교사 시연, (2) 정지 직전·넘어선 상태에서 감속/후진/회전으로 회복하는 성공 시연, (3) 새 seed와 더 넓은 미사용 조건의 고정 비교다. 교사도 해결하지 못하는 상태는 먼저 교사의 행동 범위와 감속·복구 제어를 개선하거나 다른 성공 시연 공급원을 마련해야 한다. 해당 행동 없는 데이터를 오래 학습하는 것만으로 복구 능력이 생겼다고 기대할 수는 없다. 이 후속 학습은 이번 결과에 포함하지 않는다.

- `protocol.json`, `development-protocol.json`은 실행 전 사전 계획이다. `results/`는 전체 조건 요약·감사·학습 보고서, `provenance.json`은 원본 경로와 해시다. 원본 RGB/영상/체크포인트는 로컬 outputs에만 있다. Git에는 코드·요약·일부 검토 프레임·출처를 저장하며 raw 원격 백업을 의미하지 않는다. 프로젝트 예외에 따라 Drive는 사용하지 않는다.
- 영상은 원본 화면에 인쇄된 SIM 시간을 전체 프레임 OCR로 읽고 초기/최종 물리 시각과 검사해 정렬했다. 원본 약4fps 사이에는 직전 프레임을 유지해10fps로 표시하며, 기록이 끝난 패널에는 마지막 화면 유지 문구를 넣었다. 완료 시간이 다른 원본을 단순 같은 길이로 늘리지 않았다. 실패 패널의 접근 종료 시간은 성공 완료 시간이 아니다. 영상은 시간/동작 확인용이고 물리 성공 판정은 별도 평가 로그에서 계산했다.

완료된 원본 감사: 파일 26,929개, RGB 참조 34,536개, 제어 명령 14,964개, 교사 판단 2,284개, 실제 모델 판단 735개를 검사했다. 32개 조건 모두 네 방법의 초기 전체 물리 상태·RGB가 일치했고 오류0이다. 사후 교사 진단도 원본 파일 4,428개, 교사 판단 2,502개를 검사했다.
