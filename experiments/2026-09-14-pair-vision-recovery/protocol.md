# 영상 추적·공동 정지 후 재획득 비교

관련 이슈 #39, 선행 지도·baseline PR #45. 실행 전 소스와 이 프로토콜을 커밋한다.

## 가설과 변경 범위

baseline 실행 SHA `f4da89ec53fed15c9efcea2e8bee19b99de31dfc`의 네 영상 중단은,
초기 인식과 시간 연속 추적을 분리하고 검증된 바퀴 외관을 기억하면 줄일 수 있다.
인식 불확실 상태는 두 로봇 zero 명령 후 새 영상 3회 연속 확인으로만 재개한다.
복구에는 최대 25회×0.2초를 허용한다. 관측 갱신은 빔·두 로봇이 모두 통과할 때만 한다.

새 모드는 명시적 `--vision-mode temporal`이다. `legacy`는 이전 기록의 정확한 입력
재생과 대조 실행용으로 유지한다. 바퀴 초기 기준 0.48은 보존하고, 그 기준에 미달할 때만
최근 확실한 RGB 외관과 원본 외관의 위치 일치·점수를 함께 검사한다. 빔 추적은 이전 선과의
거리·방향, 보이는 길이·폭, 고정 물체 길이로 제한한다. 초기 빔 인식은 기존 조건이다.

이번에는 A*·경유점 완료 조건·운동 gain·파지 감시·카메라·FOV·외관·지도·질량·마찰·집게 힘을
변경하지 않는다. own RGB는 기존과 같이 입력 유효성 검사에만 쓰며 파지 감시 구현을 주장하지 않는다.
실시간 정답·접촉·관절은 평가 출력에만 사용한다. 외부 LLM 호출은 없고 weld OFF를 유지한다.

## 사전 검증

1. 네 baseline 중단 기록 전체 RGB 재생: 새 감지기의 탈락/인식 수와 정상 baseline과의 위치 차이.
2. 실패 직전 RGB에서 형성한 상태와 실제 마지막 입력을 fixture로 보존하고, 픽셀 격자에서
   직접 검토한 바퀴 중심(8 px 허용 오차), 가림·복구·시간 초과·부분 상태 갱신을 회귀 검사한다.
3. 픽셀 재생은 새 행동에 따른 실제 궤적이나 완주 성공의 증거가 아니다.

## 실제 물리 검증

같은 grasp 학생과 fixed start, `impratio=10`, noslip_iterations=0, weld OFF,
파지 후 고정 8초 대기, 최대 750회 판단, 각 실행 최대 wall 600초를 유지한다.
좁은 문·L자부터 시작하여 S자·엇갈린 장애물·우회 분기·완전 차단까지 같은 후보 SHA로
순차 실행한다. 실행 중 소스를 바꾸지 않는다. 후보를 바꾸면 새 실행 ID로 구분하며 실패를 보존한다.

비교 대상은 동일한 조건으로 완료한 `2026-09-14-pair-terrain-trials`의 6회다.
통과 가능 지형 5개의 실제 운반·내려놓기 완주, 완전 차단의 공동 정지를 각각 판정한다.
새 모드의 결과를 단일 고정 시작 1회 비교로 한정하며 최적성·일반 성공률을 주장하지 않는다.
영상 중단 감소 외에도 벽/비허용 접촉, 파지·높이 유지, 목표 오차, 시간·판단 횟수,
복구 횟수·대기 시간, 모든 명령의 입력 재생 감사와 시각 검토 범위를 기록한다.

원본은 새 로컬 outputs 폴더에, 요약·설정·선택 영상·전체 원본 해시는 experiments에 보존한다.
실행에는 ugrp_session 래퍼를 쓰고 작업 종료 시 해당 프로세스 종료를 확인한다.
