# 공통 RGB 실행기의 물리 완주 복구 (2026-09-23)

## 판정 범위

## 실행 계약과 보존

모든 실행 소스를 먼저 커밋하고 깨끗한 체크아웃에서 재생했다. 후보별 JSON 실행 번들, 실제 적용 물리·카메라·명령 일정, 모델·지도·환경·원본 해시를 manifest와 결과에 보존했다. v1~v4는 완료된 실행이고, 현재 검증 중인 후보는 `rgb-adapter-contact-fine-boundary-identity-v5`다. 과거 `VisualMacroExecutor` 성공 판정을 공통 `MacroQueue` 실행기에 승계하지 않는다. 각 완료 후보의 정확한 bundle ID·SHA, 소스 SHA, 2회 결과와 비용, 원본 inventory 경로·SHA-256은 [기계 판독 결과](results.json)에 있다.

원본 보고서·영상·요청 입력·명령·평가는 이 작업 환경의 `outputs/rgb-common-physical-recovery-20260923/physical-replay-<SHA7>/`에 있다. 이 폴더는 Git에 포함되지 않는 로컬 자료이며 원격 백업이 아니다. inventory는 v1 2,522개, v2 3,952개, v3 3,726개, v4 3,752개 파일을 식별한다. 결과 패키지에는 대량 영상·모델·raw를 복사하지 않았다.

관련 자동 검사와 원본 수집 검사는 실행 기록을 검증하지만, 새로운 물리 완주 근거로 대체하지 않는다. v4 전체 CI는 1,848 passed·8 skipped·205 subtests passed이고, 실행 후 source SHA·프로세스 종료·자식 정리와 원본 inventory를 확인했다. v5 소스의 전체 CI는 1,857 passed·8 skipped·205 subtests passed이며 물리 결과는 아직 포함하지 않는다.

TensorBoard의 `0923-RGB물리-1`부터 `0923-RGB물리-4`까지 후보별 단독·공동 실패와 측정값·원본 영상을 각각 별도 스냅샷으로 등록했다. `evaluation/reported_success=0`은 **전체 임무** 판정이다. 단독 상자 대상 성공은 본 기록의 사후 물체 판정으로 읽어야 한다. [TensorBoard 화면](http://127.0.0.1:6006/)은 이 Mac의 로컬 서비스가 실행 중일 때만 열린다.
