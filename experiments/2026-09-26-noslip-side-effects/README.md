# 2026-09-26 `cargo_noslip_v1` 접촉 프로필 부작용 감사 (물리 A/B, 정답 교사, weld OFF)

병합된 PR #167이 추가한 opt-in 접촉 프로필 `cargo_noslip_v1`(= `local_contact_fine` + `noslip_iterations 10`,
`sim/zone_cargo_contact.py`)에 대한 **프로필 수준 A/B 감사**다. `noslip_iterations`는 **전역 MuJoCo solver 옵션**이라,
팀 화물 때문에 이 프로필을 고르면 같은 장면의 바퀴·팔·벽·쉬는 상자 등 **모든 접촉**이 함께 바뀐다.
그 부작용을 시나리오별로 재고, 별도로 단독 운반 미끄러짐이 noslip에서 어떻게 달라지는지 기록한다.

- **범위:** 정답 교사/스크립트 명령 조건의 **물리 감사**다. RGB·학생 성공률이 아니고, 로봇 임무 성공 판정도 아니다.
- **기본값은 바꾸지 않는다.** 기존 프로필(`local_contact_fine`, `cargo_noslip_v1`)과 러너 기본값을 수정하지 않는다.
  변경이 필요해 보이면 이 README에 **새 버전 프로필 제안**으로만 적는다(8절).
- **PR #181과의 분담:** wrist 스킬 담당(PR #181)이 청록 상자 단독 운반의 약 60 s 미끄러짐 **원인 규명**
  (`scripts/probe_zone_box_grip_hold.py`, zone 스킬 장면·carry 자세, 180 s 정지)을 이미 했다.
  여기서는 그 원인 규명을 반복하지 않고, **같은 물리 질문을 프로필 수준·장면 전체 접촉으로 확장**한다.
  상대 결과를 내 증거로 합산하지 않고 독립 재현 여부만 비교한다(7절).

## 2. 시나리오 (사전 등록)

명령은 **프로필과 무관하게 동일한 스크립트 tape**(drive/wall/arm/idle) 또는 정답 교사
(`scripts/cargo_formation_teacher.py`, carry)에서 나온다. tape 시나리오는 입력이 바이트 단위로 같으므로
차이가 나면 곧 물리 차이다. carry 시나리오는 교사가 정답 기반 폐루프라서 궤적 동일성이 아니라 지표를 비교한다.

| 시나리오 | 질문 | 명령 | 로봇·화물 |
|---|---|---|---|
| `drive_commands` | 발행 명령에 대한 메카넘 구동 응답 | 전진 0.10 ×3, 옆 0.08 ×3, 회전 0.12 ×3, 후진 −0.05 ×2 (각 1.0 s + 정지 1.2 s) | r1, 화물 없음 |
| `wall_push` | 벽·장애물 접촉 거동 | 접근 4 → 정면 밀기 4 → **밀면서 벽면 따라 이동 8** → 후진 탈출 4 | r1, 화물 없음 |
| `arm_sweep` | 빈 집게 팔 응답 | 서보 3/4/5 자세 3종 + 집게 닫기·열기 + 접힘 복귀 (11 명령) | r1, 화물 없음 |
| `idle_settle` | 쉬는 장면 물체 | 명령 없음, 20 SIM s | 없음 |
| `solo_carry` | 단독 상자 파지–들기–**유지 120 s**–운반 1.0 m | 정답 교사 | r1, `cal_block` 30 g |
| `solo_hold_load` | 같은 유지 120 s, 부하 10배 (creep–부하 비례 확인) | 정답 교사 | r1, `cal_block` 300 g |
| `pair_beam_hold` | 두 대 빔 유지 120 s | 정답 교사 | r1+r2, `long_beam` 300 g |

**지표가 아닌 것:** sim step 비용·wall 시간·시뮬레이션 속도. 연구 관심은 SIM 시간의 로봇 거동이다.
호스트 부하 평균은 AGENTS.md 요구에 따라 기록만 한다.

## 3. "부작용 없음" 허용오차 (사전 등록)

코드의 기존 행동 문턱을 기준으로 정했다: 교사 접근 정렬 `APPROACH_TOL_M` = 6 mm, 구역 슬롯 판정 ±60 mm,
wrist 스킬 재장착 anchor 18 px. 이 문턱보다 작은 차이는 어떤 판단도 바꿀 수 없다.
`scripts/audit_contact_profiles.py`의 `TOLERANCES`와 `compare()`가 그대로 구현하고, 테스트가 산술을 검증한다.

| 시나리오 | 게이트 | 허용오차 (A↔B 차이) |
|---|---|---|
| `drive_commands` | 명령별 변위 | max(**2.0 mm**, 기준의 **1%**) |
| | 명령별 방향 변화 | **0.5°** |
| | tape 끝 누적 위치 / 방향 | **10 mm** / **0.5°** |
| `wall_push` | 최대 침투 깊이 | **0.5 mm** |
| | 벽면 따라 이동량 | max(**5 mm**, 기준의 **10%**) |
| | 후진 탈출 거리 | 차이 **2 mm**, 그리고 두 프로필 모두 **≥ 20 mm**(벽에 붙어 못 빠져나오면 실패) |
| `arm_sweep` | 자세별 집게 중점 | **1.0 mm** |
| | 자세별 팔 관절각 | **0.2°** |
| `idle_settle` | free body별 20 s 이동 | 두 프로필 모두 **≤ 0.5 mm**, 차이 **≤ 0.5 mm** |
| `solo_carry` | 유지 중 손가락 합력 | 기준의 **10%** |
| | 배치 오차 | **5 mm** |
| `solo_hold_load` | 유지 중 손가락 합력 | 기준의 **10%** |
| `pair_beam_hold` | 손가락 합력 / 화물 최대 기울기 / 두 운반자 간격 변화 | **10%** / **1.0°** / **5 mm** |

**공통 하드 게이트(프로필 무관, 모든 실행):** `eq_active` 최댓값 0(weld OFF), `max|qvel|` ≤ 50, NaN 표본 0.

**미끄러짐은 부작용 게이트가 아니다.** 파지 미끄러짐 감소는 `cargo_noslip_v1`의 **의도된 효과**이므로
게이트 없이 수치로 보고한다(유지 120 s 변위 mm, 선형 적합 creep mm/min과 R², 운반 중 추가 변위).

## 4. 판정 규칙 (실행 전 고정)

1. 모든 게이트 통과 → "이 7개 시나리오·3 시드 범위에서 측정 가능한 부작용 없음"으로 보고한다.
   그 이상으로 일반화하지 않는다(교사 조건·조건당 1회·`zone_wide_door` 한정).
2. 게이트가 하나라도 깨지면 **부작용 있음**으로 그 수치를 보고한다. 기존 프로필·기본값은 그대로 두고,
   필요한 변경은 8절에 **새 이름·버전의 프로필 제안**으로만 적는다.
3. 벽면 따라 이동량은 깨질 가능성을 미리 예상해 둔다. noslip은 마찰 행의 남은 미끄럼을 없애는 후처리이므로,
   마찰 계수 1.0인 벽면에서 **미끄러지지 않고 붙는 방향**으로 바뀔 수 있다. 예상했더라도 게이트는 그대로 적용한다.
4. 자동 게이트 통과는 실제 임무 완주 재검증이 아니다. 과거 성공 판정을 이 프로필로 승계하지 않는다.

## 5. 중단 규칙

- 코호트 중 실행 소스를 바꾸지 않는다(커밋 SHA 고정, 깨끗한 트리). 도중 재조정·재실행은 하지 않는다.
- 첫 physics step 전의 인프라 예외만 1회 재실행하고 그 사실을 기록한다.
- `eq_active`가 활성화되면 그 실행을 즉시 중단하고 실패로 보고한다(weld 금지).
- 결과와 무관하게 42 실행을 모두 돌리고 실패도 전부 남긴다.
- 다른 작업의 프로세스·서버는 건드리지 않는다. 내가 시작한 세션만 정리한다.

## 7. PR #181(wrist 스킬)과의 관계

- PR #181은 zone 스킬 장면·`CARRY_POSTURE`에서 청록 상자를 180 s 정지 유지해 원인을 규명했다
  (`local_contact_fine` 2.09 mm/min, `cargo_noslip_v1` 0.016 mm/min → 수치 인공물 판정).
- 이 감사는 그 원인 규명을 반복하지 않는다. 대신 **같은 물리 질문을 프로필 수준으로** 확장한다:
  (a) 화물 목록 경로(`CargoZoneScene` + 정답 교사)에서 120 s 유지 creep을 독립적으로 재는지,
  (b) 부하 10배에서 creep이 비례하는지(인공물 서명), (c) 두 대 빔 유지에서도 같은지,
  (d) **같은 장면의 다른 접촉**(바퀴·팔·벽·쉬는 상자)이 변하지 않는지.
- 서로의 수치를 합산하지 않는다. 결론이 일치/불일치하면 그대로 적고 PR #181 코멘트로 알린다.
