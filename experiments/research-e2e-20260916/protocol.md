# 실제 RGB 공동 운반 E2E 병목 파일럿

## 사전 고정 범위

main의 PR #55/#56 통합 후, 두 독립 Gemini 3.8 Flash가 역할을 합의하고
접근 → GRASP → LIFT → CARRY → LOWER → RELEASE를 시도한다.
실험 전에 실행 소스를 커밋하고 두 조건 동안 변경하지 않는다.
이는 L2 최소 실행 가능성 진단이며, 3대 혼합 작업 전체 연구나 소통 효과의 통계 검증은 아니다.
미병합 물리 개선 PR은 포함하지 않는다. 로봇 로컬 담당자의 완성된 정책 대신
현재 제공 가능한 직접 RGB→원시 명령 LLM을 진단용으로 연결한다.

초기 조건 순서는 natural, none, 각 seed 11 한 번이다. natural은 상대 모델이 직접
작성한 자연어를 다음 턴에 전달한다. none은 메시지를 전달하지 않는다.
두 조건 모두 동일한 동기화 계약, 모델, 자기 명령 이력과 직전 영상 쌍을 쓴다.
none은 자연어 메시지만 OFF이며 공통 역할·단계 계약까지 제거한 무통신 조건은 아니다.
역할 불일치는 중앙에서 고치지 않는다. 보고서의 READY/DONE을 생성하거나 보정하지 않는다.

기존 run_camera_pair_transport.py의 평지, 일반 주황 빔, 초기 배치와 카메라/FOV를
그대로 사용한다. 카메라를 집게가 보이도록 옮기지 않는다. weld OFF.
정적 scene descriptor는 버전 식별용이며, 경로 지도나 동적 상태가 아니다.
모델에는 자기 RGB, 공용 TOP RGB, 직전 RGB 쌍, 자기 발행 명령, 고정 작업·명령 설명,
단계 맥락, 합의한 역할, 조건에 따른 상대 주장만 들어간다.
평가 좌표·접촉·관절·성공 판정은 별도 파일에만 저장하며 실행 분기에 쓰지 않는다.

## 예산과 중지

- 역할 합의 최대 4턴, 행동 최대 40턴, 턴당 실제 모델 요청 2회(최대 88회).
- 요청별 30초 제한, 조건별 600초 벽시계 및 180,000 보고 입력 토큰 기준.
  예산은 턴 시작에 검사하므로 마지막 요청 쌍만큼 초과할 수 있다.
- 명령 임대 .2 SIM초, 턴당 .3 SIM초. 모델 추론 중 물리는 정지한다.
  비동기 실물 지연이나 통신 지연의 타당성을 주장하지 않는다.
- 12턴 연속 능동 명령 없음, 잘못된 응답/모델 오류, 역할 합의 예산 소진 시 중지.
- 마지막 2.2 SIM초는 고정 정지·안정화. 평가 결과로 시간을 늘리지 않는다.
- 금액은 프록시가 주지 않으므로 null, 입력/출력 토큰과 시간·명령 수를 기록한다.

## 완료 기준 및 병목 판정

모델의 모든 단계 DONE과 물리 성공을 별도로 기록한다. 물리 성공은
보조 고정 없이 두 집게의 양쪽 접촉과 3cm 이상 상승이 2초 연속 유지되고,
최종 1초 동안 목표 영역의 위치·자세·높이 조건을 만족하며 양쪽 로봇의
모든 손가락 접촉이 없어야 한다. 카메라와 형상 불변도 확인한다.
접촉/좌표는 이 최종 평가에만 사용한다.

최초 미완료 단계의 실제 입력, 판단, 발행 명령, 영상 변화로 병목을 좁힌다.
도달하지 못한 단계는 미검증으로 남긴다. 두 번 실패해도 물리적 불가능이나
소통 효과 없음으로 일반화하지 않는다. 잘못된 새 연결 코드로 실패하면 원본을
보존하고 수정 SHA에서 두 조건을 다시 실행한다.

## 증거와 재현

`scripts/ugrp_session.py run NAME -- <mjpython> scripts/run_research_camera_e2e.py
--output outputs/NEW-ID --communication natural`로 실행한다. none은 별도 출력 사용.
실제 HTTP 본문/응답, 요청 생성 입력, JPEG, 상대 발언, 명령, 동기화 이벤트,
영상, 평가 전용 시계열, 환경, SHA256을 로컬 outputs에 보존한다.
실행 후 입력 재구성·전송 본문 일치와 메시지 출처를 감사하고 영상 구간을 검토한다.
설정·집계 결과·감사·검토 범위는 이 폴더에 기록한다. raw는 Git 제외이며 로컬 보관이다.

## 연결 사전 실행에서 발견한 결함

`ce8344d` natural 실행은 역할 합의 후 첫 PREPARE에서 양쪽 모두 checks에
자유 문장을 반환해 거부되었다. 프롬프트가 enum 전체와 자유 서술 금지를
명시하지 않은 연결 결함이다. raw `outputs/research-e2e-ce8344d-natural`을 보존한다.
검증기를 완화하거나 내용을 대신 고치지 않고 허용 enum을 프롬프트에 명시한다.
이 수정 후보에서 natural/none 전체 조건을 다시 실행한다.

## 진단 반복의 범위

수정 후보 첫 natural은 4턴 역할 진동, none은 PREPARE 호출 시간 초과로 끝났다.
이후 같은 SHA/seed/예산으로 natural, none 순서의 반복 실행을 각 1회 추가했다.
실패 기록을 대체하지 않으며, 역할 합의와 접근 이후 상태를 더 관찰하기 위한
사후 진단 반복이다. 확증 실험이나 같은 초기 SIM seed에서의 결정론 재현으로 취급하지 않는다.
