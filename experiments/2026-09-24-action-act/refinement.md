# ACT 행동 학습과 영상 기반 접근 보정

첫 모델은 실제 8,000 optimizer update를 완료했지만 선택된 체크포인트가 학습 9개·개발 4개 에피소드의 종료를 모두 놓쳤다. 완료된 학습과 사용 가능한 제어기를 구분하며, 이 모델을 성공 모델로 채택하지 않는다.

첫 6회는 기준 RGB 1/2, 후보 RGB 1/2, ACT 0/2 완주했다. 양쪽 RGB가 동시에 성공한 위치가 없어 개선율을 산출하지 않는다. [정정된 코호트 요약](first-cohort-summary-v2.json)과 [원본·예산 감사](first-cohort-closure-v2.json)를 따른다. ACT 기록 126건의 입력·응답은 검증했지만, a 실행의 마지막 캡처는 owner 중단으로 결정 로그가 빠져 추가 요청 0–2건이 미확정이다. 기존 v1 집계는 보존하되 이 v2 감사 범위를 우선한다.

## 사전 고정한 두 번째 후보

- ACT 구조·입력·데이터·seed·8,000 update와 종료 임계값 0.65는 유지한다. 기존 chunk L1+KL에 실제 배포 경로의 첫 행동 종료 출력에 대한 class-balanced MSE(weight 1.0)를 추가한다. 배포와 같은 zero-latent forward에는 목표 행동을 넣지 않는다.
- 개발 집합에서 조기 종료와 종료 누락이 없는 체크포인트를 우선한다. 통과 모델이 없으면 실패가 가장 적은 모델을 진단용으로만 저장한다. 이 오프라인 기준도 새 물리 실행 성공을 뜻하지 않는다.
- 단독 상자 접근은 큰 영상 오차가 두 번 연속 확인되고 줄어드는 경우에만 servo 보정 상한을 8에서 24 PWM으로 늘린다. 자기 RGB 형상·신뢰도·목표 연속성·발행 명령 상태를 검사하고 기존 안정화·새 영상·최종 파지 조건을 유지한다.
- 기존 추적이 실패한 뒤에도 화물이 직접 보이는 경우에는 최근 직접 관측 두 장과 관측 간격으로 제한한 영상 탐색 영역을 사용한다. 현재 자기 RGB의 부착·원본 해시, 유일한 강한 cyan 실루엣의 색·크기·움직임을 함께 검증한다. 숨겨진 화물 위치를 만들어내지 않는다.
- ACT는 두 로봇의 별도 worker에서 각각 CPU 1 thread로 병렬 추론한다. 이전 영상의 JPEG 변환과 고정 CNN 특징은 입력이 같을 때만 재사용한다. 모델 입력·출력 형식은 유지하며, 실제 ACT 회귀에서 출력 오차 2e-6 이내를 확인했다. 전체 입력 공간에서 bitwise 동일성을 보장하는 주장은 아니다.
- 관측 유효시간 0.6초와 명령 최대 lease 0.25초는 유지한다. 실행할 수 있는 시간이 20ms도 남지 않으면 새 관측을 요청하며, 중단·폐기된 실제 모델 요청도 기록한다.
- 실시간 정답 위치·측정 관절·접촉·평가 결과는 학생 제어기에 전달하지 않는다. 기존 카메라·물리·weld OFF 조건을 유지한다.

실행 전 조건은 [refinement-protocol.json](refinement-protocol.json), 3개 위치·3개 제어기 비교 순서와 한도는 [refinement-evaluation-design.json](refinement-evaluation-design.json)에 고정했다. 첫 6개 물리 비교 종료 후 소스와 모델을 고정하여 새 비교를 시작한다. 실패 실행도 포함하며, 실패까지 걸린 시간을 완주 속도 개선으로 계산하지 않는다.

기존 RGB 14장의 회귀 분석에서는 초기 큰 오차의 7개 연속 쌍에서만 빠른 분기가 허용됐다. 실제 완주 시간 절감은 아직 확인되지 않았고, 20초 절감이나 새 지도 일반화를 가정하지 않는다. [영상 분석 기록](approach-rgb-gate-replay.json)
